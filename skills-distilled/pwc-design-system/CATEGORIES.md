## How a new style joins (unlimited styles, mastered one at a time)

A new style learned becomes a new part (or a new specialist's training
material — see `design-system/AGENTS.md`). The mastermind grows by ADDING
specialists and parts, never by rewriting the whole system. Steps: harvest
→ quarantine + scan (SAFETY.md) → distill into a part (≤50KB) → file under
its category → add a row here + in COVERAGE.md → fold into the next skill
version → upload → verify ON → update the SKY-SCORE if it touches a Sky
device (see `design-system/SKY-SCORE.md`).
