## 4. THE COMMON RECIPE — draft permanent skill (SKY-15 SYSTEM)

*What the 15 share that the rest of his grid does less: the rest of the grid has the desk, the captions and the frameworks — but the priority 15 are the ones where **every** element below fires together: a named system, a graphic that builds in sync with speech and stays visibly unfinished, one concrete example per claim, and a CTA that is structural (a door, not a shout). Written as rules + recipe + parameters so it can be lifted into a skill file as-is.*

### 4.1 Identity
- **Name:** SKY-15 SYSTEM (Q adaptation: PWC SKY LANE)
- **Use when:** Q films a teaching, doctrine, proof-led, breakdown, or launch talking-head and the video teaches ONE named system.
- **Do not use when:** couples content, pure story/vlog with no system to teach, or any video whose power is a single emotional beat (use the confessional lane, Reel 15's *pacing* only).

### 4.2 Hard rules (never break)
1. **One named framework per video.** The name is coined before the shoot, appears on screen within the first 10% of runtime, and the video is that framework *filling in*. No name = no Sky lane.
2. **The hero graphic is visibly unfinished until the payoff.** A board, stack, index, chart or timeline stays on screen (or returns at every section) with its missing parts obvious. Completion = the visual payoff, timed with the closing line.
3. **A graphic state-change at every section boundary, and an example at every claim.** No claim is spoken over a bare talking head when a real screen, example clip, or diagram state exists for it.
4. **Two text layers, never merged:** (a) caption stream D1 — speech only; (b) graphic layer — framework names, devices, figures. Captions never carry the framework; graphics never transcribe speech.
5. **Face is sacred (Q override):** no device over Q's face at any zoom. Sky places graphics over his own torso and in the top band; Q's lane uses chest band, side zones, and the top stack *below* y=280 only.
6. **Colour override (Q):** Sky's accent green (#40BB2F core, §1 D2) maps to **Q teal for structure** (titles, numerals, outlines, keep-verdicts) and **Q gold for payoff** (figures, the completed state, the swapped power word, wave 2). White stays white. **No red anywhere** (Sky's reject treatment is verified — strikethrough + **red X pop**, approve = green check [BROWSER-VERIFIED Nov 6] — Q's remap: strike stays, **X in gold, check in teal**).
7. **Words never clipped (Q):** cuts land on sentence boundaries or device beats; caption groups never straddle a cut mid-word.
8. **Real screens over drawings (Q):** profiles, grids, analytics, documents are real recordings (D10). Drawn diagrams (D4–D7, D12, D13) are built from CapCut native shapes/text — never ffmpeg/PIL plates, never fake analytics.
9. **Proof ethics (Q):** figures on screen are Q's real numbers or clearly-labelled worked examples. Sky's numbers (1.1M, 97%, 1,000→100/700) are *his* case data — the *device* transfers, the data never does. Hidden-method screenshots follow Q's blur spec (faces/pics/names/brands + top-right payout blurred; followers, per-video earned, paid-ago sharp).
10. **CTA is a door, not a shout:** the close offers the framework as a take-home (keyword) and/or the follow — built into the last section, never an unrelated end-card blast. Q's keyword for the video must have a live ManyChat flow before posting (Q's standing coverage rule).

### 4.3 The recipe (execute in order)
**Pre-production**
- P1. Coin the framework name (2–4 words, ownable: a Filter, a Fit, a Stack, a Split, an Anatomy). Write it on the shoot brief.
- P2. List the framework's parts (3–6; 4–5 is the sweet spot — the 15 use 3, 4, 5, 6, 7; above 6 only for the caption-system meta format). One part = one section = one device state.
- P3. For each part, pre-select its **example asset** (real screen, clip, figure, or rewrite pair). A part without an asset gets merged or cut.
- P4. Write the hook as one of the four proven formulas (§4.4). Write the close as the framework's completion line + door.
- P5. Post caption: draft Q's two-door version (§4.7) *before* the edit, so the editor knows which door the video must point to.

**Shoot**
- S1. Medium shot, face in the upper-middle, **empty space above the head and at the chest band** reserved for D3/D1. Dark/quiet background; the set must never compete with the graphic layer.
- S2. Deliver part-by-part with a breath at each boundary — the editor's state-changes need clean sentence edges.

**Edit (CapCut, native only)**

- E2. Captions: Auto Captions → re-segment to **1–3 words per group** (D1 spec) → apply the locked Q Sky-lane caption style (one weight per video — bold era A for doctrine/teaching, light era B for process/casual) → position chest band, face-clear.
