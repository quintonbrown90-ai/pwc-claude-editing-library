## 2. Format — Format S (screen-demo teaching), DM-script subtype
Talking head + ONE DM thread, built message by message in order, the script itself the content. Structure: notification-stack hook (follow → payment) → message 1 (the opener) → the frame (not selling, just asking) → message 2 (the problem question) → the link (problem → product) → the worked example (weight loss → $199 plan) → the warning (don't fuck up the pitch) → the elevator pitch (2 sentences max) → the closer (more details?) → the 7/10 odds → the qualify → 10 messages later (client) → the automation upsell → comment VIRAL FLOW.
- **Format note:** Format S-long as defined (DMiT4yrsRNa, seven-mock chain) is a chain of DIFFERENT mocks (DM → Zoom → story → Stripe). This reel is ONE thread built in sequence — same grammar (hook → screen shown → CTA mock), but the "screen" never changes, only the messages inside it grow. Proposed subtype: **S-script** (single-thread build). S-long chains mocks; S-script grows one thread.
