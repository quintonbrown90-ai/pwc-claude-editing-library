## What this skill does

Takes a viral video or script from a **completely different niche**, extracts its **hook skeleton** (the hook rewritten as a slotted template), remaps **only the topic** onto Q's brand, and writes the **whole script in Q's voice** following the original's structure beat for beat.

**This is structure theft + topic remap. It is NOT reposting.** Keep the SHAPE, write NEW words in Q's voice, remap the topic fully to his brand — never lift the original's sentences verbatim beyond the skeleton frame itself.

**Sibling, not duplicate:** `viral-rewrite-skill.md` is the same-NICHE flow (`/ccc-viral-scripter` — same hook, same structure, same length, new value, with the outperformance gate). This skill is the CROSS-NICHE flow: the source comes from outside Q's niche on purpose, so the shape is proven but the surface is uncontaminated — the result reads as an original idea, not a cover version. When Q has a source in his own niche, run the viral-rewrite skill; when the source is from another niche, run this one.

## The 4-step method (CCC's run, as shown on screen)

1. **Take the reference from a completely different niche.** A viral video/script whose hook clearly worked. The further the niche, the cleaner the remap.
2. **Extract the HOOK SKELETON.** Rewrite the reference's hook as a slotted template — every concrete topic element becomes a bracketed slot; every structural element stays literal. CCC's own demo skeleton (VERBATIM, frames f13/f25):
   > "I went from [starting number] [unit] to [end number] in [timeframe] [doing it the way that sounds too easy]."
3. **List WHAT MOVED vs WHAT STAYED.** The audit, written out every run — CCC's demo (VERBATIM):
   > "What moved (topic): the unit (followers → pounds), the start and end numbers, and the method."
   > "What stayed (structural): the 'I went from X to Y' frame, the specific timeframe (4 months), and a method at the end that sounds too easy to be true."
   Rule: if a structural element moved, the hook weakens — put it back. If a topic element stayed, the script is a copy — remap it.
4. **Write the WHOLE script in Q's voice**, following the same exact structure from the original, beat for beat — not just the hook. Every beat of the reference gets the same beat, with Q's topic and Q's words, in Q's positions.

## Hard rules (bind every output — no exceptions)

1. **NEVER a million-dollar claim.** Q has NOT made a million dollars. No "million", "seven figures", "my first million" in any hook, script, or caption — even if the reference's skeleton has a number slot that invites one. Earnings phrasing: high six figures, "close to half a million off content so far."
2. **Numbers come ONLY from Q's real, verified proof.** If a skeleton slot needs a number Q has not provided, use a clearly-marked placeholder (e.g. `[Q'S NUMBER]`) or ask — **NEVER invent a figure.** This applies to follower counts, dollars, timeframes, and results.
3. **Never name the hidden UGC earnings app** in public content. It is the hidden method / opportunity only, revealed inside the Premium community.
4. **Never present a fabricated example as one Q actually sent or lived.** Fictional examples must read as illustrative, never as Q's real emails, DMs, or results.
5. **Q's facts:** he is **36**, he has **five kids**. If a remap needs his age or family, those are the numbers.
6. **No verbatim lift.** Beyond the skeleton frame itself, the reference's sentences are never reproduced in Q's output — new words, Q's voice, topic fully remapped to his brand. A draft that could be mistaken for the source creator's script FAILS — rewrite it from the skeleton, not by rewording the source.
7. **Clean and faith-aligned**, always. Doors-closed-until-Dec-7 discipline on every CTA.

## PWC worked shape (how a run looks for Q)

A reference from, say, the fitness niche with the "I went from X to Y" skeleton remaps to Q's world by moving the unit (pounds → deals / followers / dollars **from Q's verified proof only**), the numbers (Q's real ones or marked placeholders), and the too-easy method (Q's actual system — e.g. the hidden method, never named). The frame, the timeframe slot, and the too-easy-method slot stay. The beats stay: hook → "And yes…" → "All you need is this X right here and a Y" → concrete example → mechanism → comment WAITLIST. If the verified numbers for a slot don't exist yet, the run returns the script with the placeholder marked and flags it — it does not fill the slot with an invented figure.
