## The 1,000-hook bank (target)
His count sets the target size for Q's hook bank: **1,000 hooks**. The bank grows from:
- The library's existing hook parts (Adilet patterns, Ava 7 types, hookscore 26 formulas, Jev hook bank — parts/hooks/).
- Every shipped Q hook, scored by its post's performance (views/shares/saves — the AUDIT loop feeds the bank: winners stay, losers retire).
- The weekly outlier sweep (niche-outliers pipeline): top-10 outliers per niche → their hooks, rewritten in Q's voice, banked with their outlier multiple.
- Rule from the hookscore kill-gate: score every hook BEFORE shooting; STRONG ≥70 / OK ≥50 / below 50 = rewrite, do not shoot. The bank is a bank of SCORED hooks, not a list.
- Retirement rule (Jev): retire tired shapes on evidence — a hook shape that has stopped working leaves the bank, however many times it won before.

## The Video Breakdown as a Playbook input (DfFUHjDqewW)
The breakdown skill is how new structures ENTER the Playbook: paste a reel → frame-by-frame watch → outlier multiple (views vs creator's usual) → beat map with a psychology label per beat → reusable template. His worked example (f_027, transcribed verbatim in that DECODE.md) labels beats: Promise / "I can do this" / Self-relevance / Reveal + modeled reaction / Proof / Extra value / Reciprocity (low effort). "Not to copy them but to understand why certain beats in content work so I can improve mine going forward." — his words, and the library's stance on style recreation. A breakdown whose template does not map onto one of the 12 structures proposes a new structure (see rule above) — it does not silently become a 13th.

## Executable steps
1. Pick the structure FIRST (from the 12), before any drafting. Name it in the script header.
2. Pick the hook from the bank (scored ≥70) or write 10 fresh hooks, score them, shoot the highest STRONG one.
3. Fill the structure from the Brand Brain + the brain dump — never from a cold prompt.
4. Run the Quality Gate (see `quality-gate.md`) before Q sees the draft.
5. After posting, the AUDIT loop scores the hook against views/shares/saves and updates the bank.

## Psychology check (runs inside the Quality Gate — v9 psychology layer)

Every script passes this check before it reaches Q. A script that fails
any line is re-briefed, not shipped.

1. **The five jobs:** name the ONE job this script must do best
   (watch / stop / share / save / comment) and the second job it must
   also do. Write both in the script header.
2. **The loop:** write the big loop as one question + the beat where it
   closes (payoff at 75–85%). Kallaway check on the hook: Context →
   Lean → Contrarian Snapback. Read the first 1–2 sentences back: is
   the context clear, and is there something curiosity-inducing?
3. **The feeling:** write the emotional beat map — one feeling word per
   section (frustration / curiosity / relief / proof / celebration).
   The video's feeling must match the viewer's feeling at that beat
   (emotional synchrony).
4. **The avatar line:** the first line names the avatar in THEIR words
   ("creators under 10K, posting for free"). Shannon's test: would the
   viewer think "okay, he gets me"?
5. **The proof object:** every claim has its proof object named in the
   script (real screen / figure / example / third-party reel). No proof
   object = the script is NOT ready — source it first, never ship the
   claim bare.
6. **The close:** one action, one sentence, keyword flow live BEFORE
   the post. Name the 3 Cialdini principles + 1 buyer trigger the close
   activates. Fewer than 3 principles = the close is thin.
7. **The belonging check:** does the script use the tribe's words?
   Does it end open, pointing at the next video / keyword / live? Is
   the proof plural and real?
