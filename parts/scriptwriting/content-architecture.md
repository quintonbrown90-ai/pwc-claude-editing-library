## The rule
Claude writes scripts in your voice only when three layers are in place BEFORE any script is requested. Without them, "your scripts come out super generic and sound like AI slop" (his words). The layers run in order, and each layer is a file set, not a prompt:

1. **Brand Brain** — 3 files that tell Claude who you are, what you sell, and how you talk. "This helps Claude strategically direct each script to target the goals of your business." → `brand-brain.md` (this lane).
2. **Playbook** — "a thousand viral hooks and 12 script structures that keep showing up in content that's already worked for millions of people." → `script-structures.md` (this lane) + the hook bank (target: 1,000 hooks).
3. **Quality Gate** — "Before you see anything, Claude runs quality control on your scripts, hooks, ideas, so then everything that you get back is already vetted." → `quality-gate.md` (this lane). Pairs with the 95-gate (charliehills) as the numeric threshold.

"When you bring all of these together, Claude has a full understanding of the goals and how you talk in your content, it's a complete game changer."

## The run procedure (the 4 steps, Ddq9JE2q4-B)
The architecture is the setup. The run, per his extended cut, is:
1. **Brain dump** — talk into a speech-to-text app (he uses Wispr Flow) for 15 minutes. No AI yet. "This is where your ideas and creativity can actually flow through."
2. **Go deeper** — pick the idea that excites you; brain-dump on it again. "Think about how it relates to you, your ideal follower and anything else that inspires you."
3. **Claude structures it** — paste the brain dump into Claude "to turn your messy thoughts into a strategically structured script." Claude works from the Brand Brain + Playbook, not from a cold prompt.
4. **Edit until it sounds like you** — "check every line to edit and make sure that it actually sounds like you. This is where the fundamental understanding of scriptwriting is super important and taste comes into play." Step 4 is the human taste pass — the last gate, and it is NOT automatable.

The diagnosis that frames the whole lane: "Most people don't know this, but they're using Claude in the wrong step with the scriptwriting process. So the output that they get is super generic." Claude in step 3 only — never step 1.

## The container (AI OS shape, Dd6s9X5KhST)
One assistant, one folder, four sub-folders: `context/` / `active projects/` / `memory/` / `archive/`. The Brand Brain's 3 files live in `context/`. The Playbook lives in `context/` (reference) with the active script run in `active projects/`. The Quality Gate is a step, not a folder. "Stop collecting AI skills you're never going to use. You don't need 40 skills or 100 agents. You need one assistant that knows your business and actually gets used every day." / "Once your system is set up, use it every day and it gets better over time." — the memory folder compounds; the gate + the audit feed it.

## The interview front end (Grill Me mechanic, DehJEQMAJay — Matt Pocock's skill, credit him)
Instead of prompting Claude for a script, Claude interviews the user: one question at a time until the idea becomes a plan, with a recommended answer for every question ("so you can just say yes when it's right"). Options as multiple-choice cards with one-line descriptions, Skip, and free-text fallback ("Or reply directly…"). For Q's lane: the interview asks idea → angle → proof → CTA, one question at a time, recommended answer pre-selected. Q approves rather than authors.

## Executable steps (Q's script lane)
1. Build the Brand Brain (3 files) — see `brand-brain.md`. No script work until these exist.
2. Build the Playbook — 12 structures mapped onto Q's script structures (Authority-30, YAP30, proof-led) + hook bank grown toward 1,000. See `script-structures.md`.
3. Set the Quality Gate — numeric threshold from the 95-gate; gate runs on scripts, hooks AND ideas, before Q sees anything. See `quality-gate.md`.
4. Run the 4 steps per script: voice brain-dump (15 min, no AI) → go deeper on the exciting idea → Claude structures from Brain + Playbook → human line-edit (taste pass).
5. Audit monthly (DfKWT3Xkmwz): rank shipped reels by views/shares/saves → top-5 vs bottom-5 psychology → feed the winners back into the Playbook and the memory folder.
