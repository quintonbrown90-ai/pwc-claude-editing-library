## The rule
What to post, when, in what order — for Q's lanes. The calendar is a
strategy, not a schedule: every slot answers "what does this post DO?"
(proof, launch, nurture, close) before it answers "what time?"

## Executable steps
1. Own the lanes: launch proof (P/RC packs), avatar explainers, carousels
   (Sky Form 5), talking-head takes, E-series. One lane per slot; never
   two of the same lane back to back.
2. Own the WHAT'S WORKING NOW table (EDIT-ROUTER.md §7 + TRENDS.md):
   refresh weekly from measured engagement only; drop stale rows.
3. Order comes from Q in chat, never from file dates (Q's order beats
   file dates — Nov 7). A declined approval card may mean order, not
   rejection — ask before assuming.
4. Hand the week's top 3 topics to the Hook Agent (from
   CREATOR-PAIN-POINTS.md) and the top 3 devices to Motion/Caption.

avatar explainer 6:30 PM → Tue proof → Wed carousel → Fri Lab. Every
