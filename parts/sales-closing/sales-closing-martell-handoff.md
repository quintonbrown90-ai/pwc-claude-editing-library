# SALES-CLOSING — Martell opener→closer handoff + pre-handled objections (PUBLISHED)

Source: Dan Martell — Sell By Chat Playbook (public doc). V6-WIDENED-NET.md
Tier A. The spouse-objection row is DRAFT — Q's word governs.

## The rule
Opener → Closer handoff: the opener qualifies and warms, the closer closes —
never the same voice doing both jobs in one breath. Pre-handle objections
BEFORE the offer (price, spouse, timing, "will this work for me") so the
close is a confirmation, not a fight. Closed Won / Lost review after every
close: what worked, what lost it, logged as a rule.

## Executable steps
1. In the DM flow, separate the roles: value + qualification first (opener),
   offer + close second (closer) — even when one person runs both, the
   messages change voice at the handoff.
2. Pre-handle before the offer: name the objection ("the $97/mo question",
   "the spouse question", "the timing question") and answer it with proof,
   then make the offer.
3. Spouse objection (DRAFT): acknowledge the partner as a decision partner,
   offer the First-7-Days PDF + the graduation date as the shared picture —
   [NEEDS Q'S WORD] before this row is used live.
4. After every close: Won/Lost note — one line, what decided it. Losers
   become rules; winners become templates.

## Worked example (PWC)
Waitlister DM: value (3 Wins PDF) → qualification ("posting for free right
now?") → pre-handle ("$97/mo, founding window closes Dec 13 — that's the
real deadline") → offer (join link Dec 7) → Won/Lost note.
