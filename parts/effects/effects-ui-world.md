# EFFECT — ui world [INFERRED reconstruction]

Source: Marc Cleroux / @tenfoldmarc reel Dew3PAQTMCs, canonical decode.
Effect 08 of 16 in his on-screen index. GATED pack — rebuild from
visible specs only.

## The rule
The tool's real UI floats around the speaker — timeline, progress bar,
effect list — so the viewer stands INSIDE the edit. Show the work, don't
describe it.

## Look (MEASURED from frames)
- f_009: editing UI panels around him — a panel reading "edit my reel"
  with progress "editing… 100%", a timeline with clip thumbnails, and
  effect chips. The UI is the world; he talks inside it.

## Executable steps (rebuild)
1. Pick 1–3 REAL UI panels (the actual editor timeline, a real progress
   bar, the real effect list) — never a redrawn fake screen.
2. Composite the panels as floating cards in the face-clear zones
   (sides + top band); each drifts in slowly (EASE OUT, 0.4s) on its
   beat, one panel per beat.
3. The relevant row highlights as it is spoken (gold row highlight +
   tick SFX) — the UI reacts to the words.
4. Panels exit with a hard cut when the beat ends; never a slow fade
   over the face.

## Trigger rule
An inside-the-edit / how-it-was-made line: "here's the timeline",
"the edit is doing this right now". The UI must prove the spoken claim
at the claim second.

## Face-clearance check
Panels live in empty space around the speaker — never over the face,
never over the chest-band captions. If the take is a close-up, use ONE
panel top-stack (y ≥ 300) instead of three.
