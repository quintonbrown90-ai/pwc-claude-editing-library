# EFFECT — teardown [INFERRED reconstruction]

Source: @stocktonwalbeck / @coursecreator360 reel DfcnEEMgsNf (0.0–5.5s,
effect 01) — his words: "10 years as a video editor, here are 17 visual
effects on steroids, the tear down." The demo build is gated behind
EDITOR -> DM — NOT chased. Rebuild from this visible spec only.

## The rule
Open the video by tearing down its own making: a title card over a
collage of the video's own raw takes + code panels + the full effect
list in a caption box. The viewer sees the machine before the magic.

## Look (measured from frames)
Title card "17 Video Effects Made by Claude" over a collage of his own
clips + code panels (`camera = DJI Mic (offset 0.925 s)` · `2:08 raw ->
0:41, last take of every name` · `rendered all 17 in this take`) + the
full 17-effect list in a caption box.

## Executable steps (rebuild)
1. Collect the raw takes + the build's own code/prompt panels (real
   screens, never redrawn fakes).
2. Collage: 3–5 raw-take stills + 1–2 code panels behind the title,
   dimmed to ~60% so the title reads. Title in Anton, PWC gold on navy.
3. Caption box lists the full effect/device set (the open loop — the
   viewer now waits for each one to arrive).
4. Motion: collage pieces pop in staggered (SPRING, 0.3s), title slams
   last; hard cut out into effect 02. Sound: pop per piece, slam on the
   title.
5. PWC skin: navy collage bed, teal/gold title, PWC badge top-left.

## Numbering
Stockton numbers every effect with a blue `NN` chip top-left + the
effect name. PWC remap: chips go GOLD text on NAVY (teal border), never
blue — same job (label the device, set the open loop), PWC skin.

## Face-clearance check
The collage sits BEHIND the title and never over the speaker's face —
if Q is on screen in the opener, the collage is a full-frame beat
BEFORE he appears, or a dimmed bed behind a face-clear title zone.

## Variants
- **Viashaan — teardown animation template** (`parts/creator-systems/
  viashaan-animations.md`): one Claude Code prompt per animation style;
  teardown dissects a value equation / anatomy on screen. Same word,
  different job — Viashaan's teardown takes a THING apart mid-video;
  Stockton's teardown takes the VIDEO ITSELF apart as the opener. One
  canonical part per job: this part is the opener; Viashaan's is the
  mid-video anatomy insert.

## Worked example
Q's launch opener: title "17 WAYS CLAUDE EDITS MY VIDEOS" over a
collage of his raw takes + the router prompt panel + the full device
list in a caption box — then hard cut to the first effect.
