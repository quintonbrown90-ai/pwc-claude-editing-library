steal: 21 effects, one line each, in 14 seconds — the viewer sees the

## Worked example (PWC)

line ("$28,800" counts up live), progress bar as the Water Line under
the thesis block, zoom punch on the payoff word, map route on the
90-day journey. NAME-ONLY entries are never used until a build spec
exists — a name is not a spec. Keyword WAITLIST.

## Human-made check
A NAME-ONLY effect is a placeholder, not a part. If Claude is asked
for "neon glow" with no spec, it invents one — and the invention is
where the AI slop comes from. The catalog lists the name; the build
spec is a separate job, done once, saved as a skill.

## PWC skin

NO RED) before any use; gradient fill uses teal→gold only. The
catalog itself ships as an index, not as 21 invented builds.
