# EFFECT — backstage [INFERRED reconstruction]

Source: @stocktonwalbeck / @coursecreator360 reel DfcnEEMgsNf (~33–35s,
effect 17, the closer) — spoken in the list run. The demo build is
gated behind EDITOR -> DM — NOT chased. Rebuild from visible spec only.

## The rule
On the process moment, show the review/feedback interface — the screen
recording of the tool where the work gets judged. The process IS the
proof.

## Look (measured from frames)
Screen recording of a video review tool (timeline with markers,
1:03/1:14, comment box "Leave feedback at 1:03…", "Stockton") with his
video small in the centre.

## Executable steps (rebuild)
1. Screen-record the REAL review tool (Q's actual review/feedback
   interface) — timeline with markers, timecodes, comment box. Never a
   redrawn fake; never invented comments.
2. Layout: the tool fills the frame; Q's video plays small in the
   centre of the tool (picture-in-picture inside the interface). The
   markers + timecodes are legible at phone size.
3. Entrance: hard cut in ON the process line, with a soft UI-tick SFX;
   the playhead moves across the tool's timeline as Q talks (machine
   motion — LINEAR allowed). The comment box is the payoff — the real
   feedback line lands in it as he speaks it.
4. PWC skin: the tool's own UI stays as-is (it is a real screen); any
   added label is PWC gold on navy. Blur per the complete blur law
   where other people appear in the tool.
5. Trigger: a process line ("here's how it gets reviewed", "the
   feedback", "backstage"). Best as the closer — the last effect before
   the CTA, showing the machine behind the video just watched.

## Numbering
Blue `NN` chip top-left + name in Stockton's original. PWC remap:
GOLD chip text on NAVY (teal border), never blue.

## Face-clearance check
Full-frame tool screen plays BETWEEN Q's beats, not over him. If he
is on screen, the tool is a dimmed bed behind a face-clear zone, or
the small centre video is Q himself (face clear inside it).

## Variants
- **Prompt Drop** (`parts/effects/effects-prompt-drop.md`): the other
  process device — Prompt Drop shows the BUILD command, Backstage
  shows the REVIEW tool. Build vs review; use Prompt Drop mid-video
  (how it was made) and Backstage as the closer (how it was judged).

## Worked example
Closer beat: the review tool fills the frame as Q says "and then it
goes backstage" — markers at the real timecodes, his video small in
the centre, the real feedback line landing in the comment box, then
hard cut to the CTA.
