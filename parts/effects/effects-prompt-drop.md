# EFFECT — prompt drop [INFERRED reconstruction]

Source: @stocktonwalbeck / @coursecreator360 reel DfcnEEMgsNf (~21s,
effect 10) — the frame that reveals his whole pipeline. The demo build
is gated behind EDITOR -> DM — NOT chased. Rebuild from visible spec
only.

## The rule
On the "how it was made" moment, show the ACTUAL prompt + checklist on
screen — the real command, the real input file, the real steps. The
transparency IS the trust device.

## Look (measured from frames)
Claude Code terminal: `> edit effects-talking`, synced mov
(`effects-talking_synced.mov`), the 3-step checklist: `synced camera +
DJI mic (offset 0.925 s)` · `sifted 2:08 raw -> 0:41, last take of every
name` · `transcribed 106 words`.

## Executable steps (rebuild)
1. Screen-record the real terminal / real prompt — never a redrawn fake.
   The command, the input filename, and the checklist are the real ones
   from the actual build.
2. Terminal card: navy card, monospace text, gold prompt (`>`), white
   command, teal checkmarks. Placed in the face-clear graphic zone
   (side or top stack), inside safe zones.
3. Entrance: the card types in line by line (STEPS, one line per spoken
   beat) with a key-tick SFX per line; the checklist ticks land ON the
   spoken step.
4. PWC skin: PWC badge on the card; the prompt names Q's real command
   for the job (router intake / lane prompt), never a made-up one.
5. Trigger: a how-it-was-made line ("here's how I built this", "one
   prompt did all of it"). Use in behind-the-scenes content — Q's
   Claude can do the same, showing his real command + checklist.

## Numbering
Blue `NN` chip top-left + name in Stockton's original. PWC remap:
GOLD chip text on NAVY (teal border), never blue.

## Face-clearance check
The terminal card sits in empty space beside/below the speaker, never
over the face. If the take is tight, the card goes full-frame between
beats.

## Variants
- **Q's behind-the-scenes device:** same trust device in Q's own BTS
  content — show the real Claude Code command + the real checklist
  (sync offset, sift, transcript) for the video being watched. See
  `parts/render-pipelines/pipeline-stockton-one-prompt-render.md` for
  the pipeline this card documents.

## Worked example
BTS beat: the terminal card types in `> edit effects-talking` as Q
says "one prompt did all seventeen" — the checklist ticks (synced,
sifted, transcribed) land one per spoken step.
