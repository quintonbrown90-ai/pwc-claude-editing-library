# MOTION — beat rhythm (MEASURED)

Source: Adilet `skills/adilet-system/PACING.md` (measured on all 59 reels +
deep set of 13) + Herk Edit Kit measured house style + Sky retention rules.

## The rule
The unit of pacing is the BEAT (one claim → one new proof object / pose /
number), not the scene cut. Nothing on screen sits still longer than ~4s.

## Measured numbers
- Adilet: median 35.5s at 222 wpm (180–300 wpm range); beat changes every
  ~1.5–3.5s (~17–35 events/min); avatar pose changes every ~1–2s,
  word-synced; CTA tail accelerates (cuts at 56.9 / 57.6 / 58.3 / 61.0s).
- Herk: shots 1.1–1.4s, pauses <0.2s, one visual per spoken phrase.
- Q's retention read: visual event every ≤2s; hook lands a claim/curiosity
  in ≤2s with the face on screen; open loop early + a second before the
  midpoint; every section ends on a mini-payoff or a new question.

## Executable steps
1. Beat-plan the video first (`design-system/templates/beat-plan.md`): one
   beat per claim, each with its proof object + motion name.
2. Count beats per minute in the plan — under 17/min, the video drags; add
   a visual event (proof swap, stamp, count-up, pose change).
3. Verify on the export: freezedetect zero freezes ≥0.35s (a frozen beat
   reads as "the video stopped").

## Worked example
A 35s proof video at 222 wpm ≈ 130 words ≈ 12–15 beats. Beat 1 (0:00):
hook + proof on screen. Beat 5 (~12s): first verdict stamp. Beat 12
(~30s): completed device + keyword CTA. Tail ≤1s after the last word.
