# MOTION — motion-design skill repo: taste baked in, not prompted (PUBLISHED)

Source: Aidan Stanik — youtube.com/watch?v=7ixWO1SeEZo
(CLAUDE-CODE-WORKFLOWS.md §20; PROMPT-PATTERNS.md §22). Beat budget: 6–8
beats per 30s voiceover.

## The rule
A skill repo that makes Claude a motion designer: SKILL.md + an 8-step
checklist Claude reads when building motion graphics, plus director /
patterns / reference subfolders carrying core philosophy, decision
frameworks, Disney principles, motion personality, emotion mapping, and
choreography. Without it, HyperFrames output is generic AI slop ("that
stupid highlight border around every single rounded pill"); with it, the
same tool produces smooth, characterful motion. This is the device-library
fix for SL-01 (same 12 components, same rhythm = "cheap AI slop"): build
the library FIRST, variety rule ≤2 uses/device/video.

## Executable steps
Build a PWC version — folder `motion-design-skill/` with SKILL.md (the
8-step build checklist: 1 read the brief, 2 pick the motion personality,
3 map emotion per beat, 4 choose pattern per beat, 5 choreograph
entrances/exits, 6 check face clearance, 7 check safe zones, 8 contact-sheet
self-review) + `director/` (core philosophy MD + decision frameworks: when
to move, when to hold) + `patterns/` (entrance/exit pattern library with
exact parameters) + `reference/` (18 style cards: PWC pop-ups, cards,
captions, each with a still).
Onboard with: "Analyze the motion-design skill. I want to start creating
videos in this style." Then clone-by-URL: "I want you to create a 30 second
video using the voice over from this [URL]. Showcase the motion design from
the kit. When this is done, open the HyperFrames studio so I can preview
before re-render. Only pull 30 seconds." Correct in Studio ("this is not
centered — move this into the center", "pop this up a little bit higher")
instead of re-prompting. The same caption style/elements work for reels,
YouTube, and instructional/client videos — not just short-form.

## Worked example (PWC)
A P-pack video: motion personality = "proof-led, gold punch"; emotion map =
frustration (slow push) → relief (overshoot pop) → proof (count-up STEPS);
patterns picked per beat from the library; contact sheet reviewed before
any render. No device used more than twice.

## PWC skin
Palette teal/gold on navy, NO RED; face clearance is checklist step 6, not
an afterthought; CapCut-native motion on the finished edit.
