## The rule
Taste lives in two files, not in a prompt. slot.md = the basic instructions
("I don't like videos like this... I like minimalist video. I don't want to
zoom in too much. I want simple videos."). style.md = all the context (what
kind of video you want; references to people; things I like, things I don't
like). Claude reads both before it touches a frame.

## Executable steps
1. **slot.md** — the brief in the creator's own words: likes, dislikes, what
   "like this" and "not like this" mean, with named reference videos.
2. **style.md** — the context file: the kind of video, the references, the
   things liked and disliked, the brand kit (fonts, colors, pacing, caption
   grammar).
3. **Test 20–30 seconds first:** run the taste files on a 20–30s cut, watch
   how it's done, tweak the files, then run the whole video. The pilot is the
   test (Q's pilot gate, same shape).
4. **Real stuff only:** real news headlines, podcasts, clips — not "motion
   graphics or animated, stupid HTML." Q's show-it rule: real footage, photos,
   screen recordings over flat plates.
5. **Save the style:** once a style lands, Claude saves it — next time, send
   the raw video and it already knows. Feedback goes in ONE message with
   timestamps (saves re-render tokens).
6. **Train-a-junior framing:** treat Claude as a junior staff member just on
   board — the first video has back-and-forth while it learns the style; the
   next takes minutes. Nothing renders until you say yes (storyboard gate).
