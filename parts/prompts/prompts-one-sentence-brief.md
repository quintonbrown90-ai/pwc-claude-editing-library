## The rule
The brief is one line. The tightest in the sweep: "Keep the good takes,
tighten my pauses, add captions, and motion graphics every 2–3 seconds" —
four verbs, one line. The 2–3s motion cadence matches Q's ≤2s visual-event
rule. One line in, the edit out.

## Executable steps
1. **Four verbs, one line:** keep the good takes / tighten the pauses / add
   captions / motion graphics every 2–3 seconds. Each verb is a job Claude
   already knows (best-take, through-edit, word-timed captions, per-line
   device). If a verb needs explaining, it isn't a verb yet — write the rule
   first.
2. **One-line edit command:** "Use [tool] and edit this video in vertical
   format" — the tool + the format, one line. Q's version: the tool is Claude
   + CapCut, the format is 1080x1920 vertical.
3. **One-line brief → structured prompt → variations:** the brief is one line
   of feel ("lifestyle feel, warm tones, close-up texture shots, premium
   brand energy") → Claude expands it into a structured prompt → one input,
   five variations (different angles, different moods, different hooks).
   Q's version: one photo / one take → 5 trial variations, hook as the
   variable.
4. **Async close:** "Kick it off, step away and come back" — the generation
   runs while you step away. Q's lane: brief → Claude edits → Muse QCs the
   render. The step-away is the wait, not the work.

## Worked example (PWC)
Q's one-line brief: "Keep the good takes, cut every pause, Sky captions one
word at a time, a device on every line." One line, four verbs, the whole
edit. Variations: same take, five hooks.

## Human-made check
The one-liner is read aloud before it runs — if it doesn't fit in one breath,
it's two briefs.
