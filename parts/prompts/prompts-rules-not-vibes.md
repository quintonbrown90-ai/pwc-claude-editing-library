## The rule
A style is just rules. Never tell Claude "edit like Nick" — AI has no idea what
that means. It knows rules, systems, processes. Claude watches the reference
videos and MEASURES them (layouts, pacing, captions, cuts), then writes the
measurement down as a 12-step rulebook document, saves it as a skill, and only
then edits. "Nick's whole look is basically just rules. So can't we just steal
the rules?"

## Executable steps
1. **Measure, don't vibe:** feed Claude 3–5 reference reels (links). It records
   per reel: layout (where the head sits, where text sits), pacing (cut every
   ~1.5–3.5s, inter-word gaps), caption grammar (word-by-word, keyword accent),
   cut grammar (what triggers a cut / zoom / pop-up). Output is a table, not
   adjectives.
2. **Rulebook:** the measurements become a 12-step rulebook document (Intro /
   Hook / Bold-and-light cut / Story / Visual inventory + 7 more named steps).
   Every step is a testable rule ("captions land on the spoken word, never
   ±0.2s off"), never a vibe ("make it punchy").
3. **Save as a skill:** the rulebook is saved as a skill, so the next video
   starts from the rules, not from a fresh prompt.
4. **Storyboard first:** drop in raw footage → Claude shows a storyboard first
   (Change / Approve) so Q improves it BEFORE the render.
5. **Self-watch:** Claude drafts the edit, then watches its own video until the
   timing is perfect — the watch is the timing check, not a human re-watch.
6. **Copy the system, not the video:** study the whole system behind a winning
   channel (its formula, its numbers, its sources) — never copy one video.
   Every number in the research carries its source (100% sourced, per
   @scottsmithyta).

## Worked example (PWC)
Sky's protocol IS a rulebook: one word at a time, center-lower, keyword in
accent color, hard cut per word, never over the face. A new style joins Q's
library the same way: measure 3 Sky reels into rules → rulebook → skill →
storyboard → self-watch → Muse QC.

## Human-made check
The rulebook is read before the render: if a rule can't be checked on the
exported file (frame + timestamp), it isn't a rule yet.
