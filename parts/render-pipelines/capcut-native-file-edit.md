# RENDER-PIPELINES — edit the REAL CapCut project by writing project files directly (Matt Loui, Tier S)

Source: Matt Loui — "Automate Your CapCut Editing With Claude (Step by Step
+ Free Skill)" (https://www.youtube.com/watch?v=U-AdnIz1jIk). INFERRED
reconstruction from the visible prompt and workflow; no files downloaded.
Knowledge entries V8-65, V8-66, V8-67, V8-68, V8-69. This is the CapCut-native
requirement (Q's standing rule) satisfied by construction, not by a render:
the edit lands as a real CapCut timeline you can tweak before export.

## The rule
Claude edits CapCut by writing the project files directly — no computer use,
do not open CapCut. The output is a timeline, not a video file. If the edit
can't be opened and tweaked in CapCut, it isn't a CapCut edit.

## Executable steps
1. **The verbatim CapCut edit prompt.** Sync screen recordings, cut repeats
   / errors / long pauses, cut between camera and screen, adjustment layer
   (saturation / contrast / lower shadows), slow smooth zooms on intriguing
   points, music from a named folder, assets must work in CapCut, ask
   questions to confirm. A complete one-shot edit brief — reuse verbatim.
2. **First-one approval gate for generated assets.** Generate the first
   motion graphic for approval with questions about visual / creative
   direction; once approved, the rest follow the same design. Same gate as
   the Opus-style-first rule — a second source.
3. **Re-analyze after human tweaks, then distill a skill.** Close CapCut,
   have Claude diff before/after and note your changes so it learns your
   style; then ask it to write a skill from the whole chat. The skill is the
   memory of your taste.
4. **Pinterest reference → download → upload → generate in that style.**
   Reference-driven motion graphics: find the style you like, hand it to
   Claude, generate in that style at the important points. Five Pinterest
   images (colors / fonts / mood, not copying) is the cheap style-training
   gate — test whether 5 is enough before defaulting to 15–20 references.
5. **Human polish is the last 10%.** Move the graphic so the jump cut lands
   smooth; fix the pause Claude missed; tweak the grade. The polish pass is
   where "professional" comes from. No video ships without it.

## Worked example (PWC)
Q's talking-head take: Claude writes the CapCut project (sync Q + screen,
cut repeats/pauses, adjustment layer teal/gold grade, slow zooms on payoff
lines, bed from the licensed folder) → Muse opens it in CapCut, tweaks the
one graphic that lands on a cut, closes → Claude diffs the tweak into the
skill → export. Keyword WAITLIST.

## Human-made check
The timeline opens in CapCut and plays clean before export: no graphic over
Q's face, no word clipped at a cut edge, the polish pass done by a human
watching the whole timeline.
