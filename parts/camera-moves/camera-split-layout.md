# CAMERA — split-first-frame + per-line layout switching (MEASURED / PUBLISHED)

Source: @nateherkai Herk Edit Kit (MEASURED house style — MIT) +
@johannships reels-engine (PUBLISHED — MIT).

## The rule
Frame one is ALREADY a split: proof/tool on top, speaker below. The layout
changes on the spoken line, never mid-sentence. Every graphic is a real
screen or official logo — never stock, never generated.

## Executable steps
1. **Split-first-frame (Herk):** open with the split up — no establishing
   shot, no greeting. The hook is visual before a word lands.
2. **One visual per spoken phrase:** every phrase gets its own visual;
   shots 1.1–1.4s; pauses <0.2s.
3. **Per-line layout switching (johannships):** when the spoken line
   changes, the layout may change. Never mid-sentence.
4. **Real-screens-only:** the proof is Q's real screen, a real screenshot,
   or an official logo. If no real screen exists, the proof is a diagram
   built from real numbers — never a stock photo pretending to be proof.

## Worked example (spec sheet 05, brand-dna)
0:00 — FIRST FRAME: split already up — the proof (real screen/tool) on
top, Q below mid-sentence. Every phrase swaps the visual on the phrase
boundary. Close: completed state + keyword CTA; logo moment ≤1s after the
last word.
