# COLOR — the PWC palette law (PUBLISHED, sampled from the logo)

Source: `design-system/BRAND.md` — palette sampled from Q's official logo:
navy #00214E, blue #013B6B, teal #14A886 / #109E90, gold #FEE238 / #F5B921.
NO RED — any reference's red maps to gold.

## The rule
Teal #14A886 / gold #FEE238 on navy #00214E. Every video, every carousel,
every caption, every diagram. A reference's red is gold here. A reference's
pastel gradient is navy/teal/gold here.

## Executable steps
1. Skin every borrowed system: colours → PWC palette; fonts → PWC set
   (Anton / Poppins ExtraBold / Playfair gold italic); logo → PWC logo,
   unaltered; voice → Q's voice; CTA → WAITLIST / lane keyword.
2. Palette check on the export: sample the frame — teal/gold/navy dominate;
   red-dominant pixels ≈ 0 (tolerance ~2–7/video as shipped on the viashaan
   demos, from skin tones / real footage only, never from graphics).
3. A graphic that cannot survive the re-skin is parked, not shipped.

## Worked example
Zeeuiux's kit uses near-black #09090A + pastel gradient #FFDCCB → #F6BDD8
→ #C9B9FF. PWC re-skin: near-black → navy #00214E; gradient → teal →
gold; text stays #F5F5F4. Same motion, same layout, PWC colours.
