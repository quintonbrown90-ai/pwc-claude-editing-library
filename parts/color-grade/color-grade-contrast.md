# COLOR — contrast + readability (PUBLISHED, partial — full recipes pending harvest)

Source: Herk caption contrast-check (in a dark box) + Zeeuiux Reel Style
Rules + PWC safe-zone law. Full colour-grading recipes arrive with the
Phase 4 knowledge harvest (`research/knowledge/COLOR-GRADE.md`).

## The rule
Every text element sits on fully opaque backing in its own clear zone, no
overlapping/ghosting. Captions are verified readable against the frame
behind them before shipping.

## Executable steps
1. **Contrast-check:** run Herk's check — captions verified in a dark box
   against the actual frame behind them. If the frame is bright, the box
   goes darker, not the text thinner.
2. **One caption at a time**, fully gone before the next. Words never
   clipped, never overlapping another graphic.
3. **Safe zones (hard):** text x 70–930, y 280–1480 on 1080×1920. Nothing
   in the top 280px, bottom 440px caption zone, or right action rail.
4. **Faces + text:** reel covers keep faces + all text + handle inside the
   center 1080×1350 grid crop.

## Worked example
A gold Playfair italic accent word over bright footage: opaque navy chip
behind it, inside x 70–930 / y 280–1480, contrast-checked against the
brightest frame in its window. If it fails the check, the chip darkens —
the word never shrinks.
