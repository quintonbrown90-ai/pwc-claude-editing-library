# GAP-FILL — Thumbnail + hook science [Q didn't ask, mastermind added]

Source: Adilet HOOKS.md (measured patterns) + Ava's 7 hook types +
Sky Form 2 + Q's cover template (locked) + P1 v9/P2/P3 (live Nov 7–8).
Mark: GAP-FILL.

## The rule
The stop happens in the first 2 seconds. The hook is a claim + a
curiosity gap, never a greeting and never "in this video."

## The cover (locked template — never improvised)
Full-bleed photo (approved set only: hands-face 9e, walking-away 33,
hands-face full-body 19EBE286, grass Q+Kiya 5c, stairs 6b — NEVER the
denim photo 09C6) + dark navy gradient + top-left navy badge with gold
border reading "PAID / WITH CONTENT" (CONTENT in teal) + huge Anton
headline left-aligned low-center with the payoff line gold + full-width
yellow pill "COMMENT <KEYWORD>" in navy text + "skool.com/
paid-with-content" in white bold centered under the pill. No handle, no
motto line. Faces + all text + handle inside the center 1080x1350 grid
crop. No cover on disk = no post.

## Hook science (what makes people stop)
- **Claim + number:** "Five emails, $92,000" (P2) — a specific number is
  a promise the video must keep.
- **Curiosity gap:** name the outcome, withhold the mechanism ("here's
  exactly how" is line 2, never line 1).
- **Pattern interrupt:** a visual that breaks the scroll — split-first-
  frame (Herk), a wall of real tiles (P1 v9), a word behind the head
  (Viashaan hero).
- **Threat + specific figure:** Adilet's LAWSUIT pattern ("sued for
  $100K") — fear with a number, run 4× in 10 days because it worked.
- **The hook is spoken AND shown:** the title words drop in AND a voice
  says them up front (spoken-hook rule, Nov 3) — a silent title is a
  missed hook.

## Executable steps
1. Write the hook from a measured pattern (Adilet 4 / Ava 7), fill with
   a TRUE PWC claim — never an invented number.
2. Put the proof on screen at 0:00 and Q's face in the first 2s.
3. Open a second loop before the midpoint (Stephanie Cater's double
   open loop) — one loop is not enough to hold a 40s video.

## Worked example
P2 hook: "Five emails, $92,000" — claim + number, proof (the emails) on
screen at 0:00, Q's face present, second loop opens before the midpoint.
