## The rule
A fixed 7-field breakdown (transcript / topic / format / idea / hook
breakdown / layout / storytelling structure) run on ONE video, then run on
DOZENS at once — the batch analysis is where the trends appear. The trends
only exist at batch level; a single video has no trend.

## Executable steps
1. The 7-field schema (fixed, same every video): transcript / topic /
   format / idea / hook breakdown / layout / storytelling structure. This is
   the same job as Jayant's Reel Analyzer (hook/beats/pacing/visuals, MIT
   repo) and Q's own DECODE.md template — the three schemas are
   cross-referenced, not duplicated. The /analyze form is the one-command
   version: "/analyze + link".
2. Link-drop research: while scrolling, copy any interesting video's link
   and drop it in — research as a side effect of scrolling, not a separate
   session. Q sends links in chat; the analyzer returns the 7 fields.
3. Batch analysis: once a set (10+ videos) is analyzed, run the batch read
   — the hidden trends (which hooks repeat, which formats cluster, which
   layouts correlate with retention). The batch read is a separate output
   (one page: the trends + the evidence for each).
4. The "in sync" rule: run a batch on one model / one schema so the outputs
   are comparable — a batch analyzed with different schemas is not a batch.
