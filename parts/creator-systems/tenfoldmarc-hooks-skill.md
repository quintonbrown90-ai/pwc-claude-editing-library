Source: @tenfoldmarc public guide guides.tenfoldmarketing.com/60k-content-system

## The rule
`/hooks [reel url]` → downloads, transcribes with Whisper, extracts the
hook, files it in a hook bank. One command turns any reel into a banked
hook — the bank grows every time Q watches a reference.

## Executable steps
1. Input: a reel URL (Q sends the link in chat — the same link-drop habit
   as Kallaway's /analyze and Jayant's Reel Analyzer).
2. The skill downloads the reel, transcribes it with Whisper, and extracts
   the hook (first spoken line + on-screen line, verbatim).
3. The hook is filed in the hook bank with: source link, hook verbatim,
   hook type (claim / question / contrast / list / story), and the
   performance where known.
4. The bank is the input to the hook miner (Ootto hook-mining part) and the
   hook doctor (Ootto virality part) — extract → rank → diagnose, in that
   order.

## Worked example (PWC)
Q drops a viral hook reel link → `/hooks` extracts "Stop posting
consistently and waiting" (claim hook, contrast type) → banked → the miner
ranks it against Q's own hooks → the doctor scores it → the winner becomes
next week's hook template. Keyword WAITLIST.

## Human-made check
The extracted hook is the creator's words, banked as a reference — Q's
version is always rewritten in Q's words before filming (never copy a
creator's script).
