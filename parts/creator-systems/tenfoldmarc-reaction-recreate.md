# CREATOR SYSTEMS — Reaction-recreate format (@tenfoldmarc)

Source: @tenfoldmarc reel DfQLBvuzBIy (Nov 2, 2026; 41.0s; 167 likes / 154
comments; funnel STUDIO) + RABBIT-HOLE-MANIFEST.md. `/video-studio` +
raw_clip.mov + reference reel link → Claude recreates the viral effect.
Gated (Studio) — command name only, no code. INFERRED reconstruction from
the visible demo.

## The rule
Reference link + raw-beat recipe + /video-studio → Claude matches the
effect grammar. The recreation is a reaction: watch the reference, name its
beats, rebuild them on your own footage. Every effect spec should carry its
raw-beat recipe.

## Executable steps
1. Input: a reference reel link (Q sends the link in chat) + Q's raw clip.
2. Write the raw-beat recipe FIRST: the reference's beats in order (hook
   beat / proof beat / payoff beat), each with what is on screen + the exact
   second it lands. The recipe is the spec; the build follows it.
3. Claude rebuilds the effect grammar on Q's footage — same beats, Q's
   words, Q's proof, PWC skin. The effect is the grammar (the move), never
   the reference's content.
4. QC: the recreation is judged against the recipe (did every beat land on
   its second? did the grammar match?) — not against the reference's
   prettiness.

## Worked example (PWC)
Reference: @tinanatwilson viral effect → recipe: 0.0s face + title drop,
0.8s proof tile, 1.4s cut to demo, 2.1s payoff card → rebuild on Q's P-pack
take with the $92,000 email wall as the proof tile. Keyword WAITLIST.

## Human-made check
The recipe is written by a human (Muse) from watching the reference — the
build never starts from the link alone. Q's footage, Q's words, Q's proof.

## PWC skin
Same grammar, PWC palette, face never covered, real footage only.
