## The rule
A two-axis matrix (formats × visual styles) that maps a niche's landscape
in one glance — every cell a format, every format linked to the videos using
it + why it works, and the EMPTY cells highlighted as the opportunity. The
gap is the product: the matrix doesn't just show what works, it shows what
nobody is doing.

## Executable steps
1. The matrix (two axes): rows = formats (talking head / proof-led /
   carousel-as-reel / tutorial / story / list / myth-bust / before-after);
   columns = visual styles (split-screen / full-screen proof /
   diagram-build / PiP / phone mockup / card stack). Every cell that Q's
   niche uses gets a thumbnail + a link + a one-line why-it-works.
2. The open-gap read: the empty cells are marked in gold ("OPEN GAP") — a
   format × style nobody in the niche is using. The gap list is the content
   plan: the next month's reels fill the gaps first.
3. The matrix is built from the harvest (333+ decoded videos, each tagged
   format + style) — not from a plugin. The plugin (sandcastles.ai) is NOT
   used; the matrix is a research output, not a tool.
4. The matrix is re-built monthly — the landscape moves, and a gap filled
   by someone else is no longer a gap.

## Worked example (PWC)
Matrix for the UGC-coach niche: talking-head × split-screen is crowded (12
examples); myth-bust × diagram-build is EMPTY — an open gap. Next week's
reel: a myth-bust ("Posting more doesn't grow you") built as a live
diagram. Keyword WAITLIST.

## Human-made check
The matrix is built from Q's own harvested references (the 333 decodes),
not from a scraped list — every cell's link is a video someone actually
watched and decoded.

## PWC skin
Gold OPEN GAP cells on a navy matrix; teal for crowded cells. Real
thumbnails, never stock.
