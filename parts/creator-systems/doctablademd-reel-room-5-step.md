## The rule
"YOUR VIDEO EDITOR IS ABOUT TO HATE THIS." "Because AI now edits my
reels. Faster and cheaper." Five steps, one room: open Code → one
install → pick a look → approve the plan → turn the best edit into a
skill.

## Executable steps
1. **Step 1 — open Claude and switch to Code:** "Open Claude and
   switch to Code." First ask: "Edit my reel in the split deck look."
   "✗ Chat answers questions / ✓ Code edits the files on your
   computer." (Same Code-not-Chat split as his 90-second setup video
   De60js9E1IR + duplicate DerpJK2jcAW: Claude Code, not Chat → folder
   → skills + Hyperframes → drop raw + reference styles → Claude
   analyzes → storyboards → you approve → first version.)
2. **Step 2 — one install:** "One install. That's it." "Make a folder,
   open it in Claude Code, paste two lines." The folder: "Reel Studio."
   The two lines (VERBATIM-FRAME): "/plugin marketplace add
   drleadflow/reel-room / /plugin install reel-room@reel-room / >
   READY". "First run sets up the rest for you." — "ffmpeg, Python and
   the HyperFrames video engine." (Plugin PARKED — see header. The
   two-line install SHAPE is the steal: folder + two lines + READY.)
3. **Step 3 — drop in your clip, pick a look:** "Drop in your clip.
   Pick a look." Look cards: "GET IN SHAPE" / "7" / "Fast." /
   "5 THINGS" / "NEW HERE" / "Physician." / "BLOOD WORK" / "KAROLINE."
   Layouts: Split deck / Editorial UI / Motion editorial / List stack.
   Motion: Slide-up / Floating cards / Clean talk / Desk demo. The
   look is picked BEFORE the edit, not discovered after — same shape
   as the style-sheet lock.
4. **Step 4 — approve Claude's plan, then talk:** "Approve Claude's
   plan. Then talk." "✓ Plan approved." The talk line: "Use my workout
   clip here." "Say what you want changed. Claude edits it and shows
   you the frame." "No timeline skills needed." The storyboard frames
   are the plan; the yes is the gate (Q's pilot gate, his shape).
   Voice-dictation feedback (from the 90-second setup video): talk
   your notes, WhisperFlow/Glido transcribes them — the note is
   spoken, not typed.
5. **Step 5 — turn your best edit into a skill:** "Turn your best edit
   into a skill." "Next time, one command runs the whole workflow
   again." "Turn this edit into a skill called evidence-reel." "✓
   Saved skill /evidence-reel ~/.claude/skills/evidence-reel/ SKILL.md
   scripts/composite.py scripts/captions.py scripts/render.py."
   "/evidence-reel." "Same style. Every time." (Same doctrine as the
   library's save-it-as-a-skill part — this is its edit-room instance.)
