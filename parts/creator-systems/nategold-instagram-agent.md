## The rule
Thirteen Claude skills that run an Instagram account — free, MIT licensed,
no signup, no API key, nothing to connect. The pack is a writing/planning
system, not a look — it slots under the router as the "plan + write + check"
row before any edit starts. Voice profile first: every skill reads
`voice.md` — "a script in the wrong voice is useless, because they have to
say it out loud."

## The pack (13 skills)
- **/ig-reel** (idea → Reel) · **/ig-viral** (find what's working) ·
  **/ig-caption** (the caption's job: ask / proof / search; Line 1 = the ask
  in the first 125 characters the feed shows; hashtags up to five) ·
  **/ig-carousel** · **/ig-story** · **/ig-profile** (12-item rubric, 100
  pts — own part: `nategold-ig-profile-audit.md`) · **/ig-plan** (weekly
  plan) · **/ig-human** (humanizer — own part:
  `parts/captions/captions-ig-humanizer.md`) · **/ig-comment** (9 types) ·
  **/ig-reply** (keyword/lead/substance/question/support/noise sort) ·
  **/ig-dm** (keyword deliveries, first messages, collab pitches, two
  follow-ups only) · **/ig-repurpose** · **/ig-audit** (rank by outlier
  multiple AND sends per reach — own part:
  `parts/strategy/strategy-outlier-multiple-swipe.md`).
- Five Python tools really run, locally, on the user's own text:
  hookscore.py, beats.py, humanize.py, detect.py, caption.py (+ swipe.py in
  /ig-viral). `beats.py` times the script before filming and flags: hook
  over 3s, any beat over 4s, stretches with nothing concrete, no loop.

## Executable steps
1. Clone the repo (MIT) → copy `skills/ig-*` into Claude's skills → write
   voice.md from 3 of Q's reels (his words, his cadence, what he'd never
   say).
2. Run /ig-reel → /ig-human → /ig-caption in that order for every post.
3. The /ig-dm keyword-delivery skill maps onto Q's existing ManyChat flows
   — the skill writes the DM copy, ManyChat delivers it; the skill never
   posts or DMs live by itself.
4. Never let a skill publish, follow, like, or message — writing only.
