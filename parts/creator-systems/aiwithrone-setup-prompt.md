# CREATOR-SYSTEMS — @aiwithrone setup prompt + reference→style guide (PUBLISHED, verbatim)

Source: @aiwithrone Devt9LwPWrJ (Tier S, BULK-DECODE-LOG.md Batch 6) — 3-
subfolder setup (reference / exports / raw) + verbatim setup prompt. The
funnel is EDIT (DM-gated setup file not chased); the prompt below is public
on-screen text, PUBLISHED verbatim.

## The rule
Hand Claude the job in plain English and let it set itself up — then teach
the style from a REFERENCE, not a description: reference → style guide
(numbered step list: push-ins, frame scale, framing shifts).

## Executable steps
Setup prompt (verbatim — paste as prompt #1):
"You are my short form video editor. Set up these tools on my computer so
you can edit my videos. Check what's already installed first. Then install
what's missing. Explain each step in plain English before you run it."
Then: reference → style guide. Give Claude a finished reference video and
ask for the numbered step list of what it does (push-ins, frame scale,
framing shifts, caption treatment, sound). That list IS the style guide —
never re-describe it in chat again.

## Worked example (PWC)
Folder: reference/ (P1 v9, P2, P3 — Q's finished videos) / exports/ / raw/.
Prompt #1 as above. Prompt #2: "Watch P1 v9. Write the style guide as a
numbered step list: every push-in, frame scale, framing shift, caption
treatment, sound." The guide becomes the lane spec for the next video.

## PWC skin
Setup explains each step in plain English BEFORE running it (Q's word
governs installs). Style guide is built from Q's own finished videos —
never another creator's words.
