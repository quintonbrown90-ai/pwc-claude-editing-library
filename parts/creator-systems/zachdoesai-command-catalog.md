## The rule
Four slash commands, one job each, in order. No slash-command literacy
needed from Q — the commands are the edit's table of contents:
1. `/clip` — "it's going to remove all the dead space in your video."
   (0.0–3.8s)
2. `/captions` — "it's going to add perfect text captions to your video."
   (3.9–7.0s)
3. `/storyboard` — "it's going to create an entire storyboard for how it
   would edit the video, and you can give it feedback so that edit turns
   out exactly how you wanted to." (7.1–14.1s)
4. `/inspiration` — "give it the link to an already edited video, it will
   teach itself how to edit videos exactly like that." (14.2–19.8s)

## Executable steps
1. Run /clip first — dead space out, cut list shown, Q approves.
2. /captions — word-exact, never over the face, safe zones.
3. /storyboard — one still per beat, feedback BEFORE any render (the pilot
   gate, in command form).
4. /inspiration — link to a finished Q video (P1 v9 / P2 / P3), never a
   stranger's video; Claude teaches itself the style from Q's own work.
5. The frame-grid "studying it frame by frame" insert is the proof the
   study happened — show it, don't claim it.

## Worked example (PWC)
Raw P-pack take → /clip (pauses out, cut list) → /captions (Sky stream,
word-exact) → /storyboard (wall → count-up → CTA, stills approved) →
/inspiration (P1 v9 link — "edit like THIS"). One command at a time, Q
approves each gate.

## PWC skin
Inspiration is always Q's own finished videos. Keyword flow live before
posting (ENGINE Step-0 gate). Nothing over the face, ever.
