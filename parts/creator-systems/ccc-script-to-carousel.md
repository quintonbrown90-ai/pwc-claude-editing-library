## The rule
Any idea — or any video script that already did well — becomes a ready-to-post Instagram carousel in your branding style. The skill does not design from a blank page: it takes a PERFORMED script as its input, so the carousel inherits a proven structure the same way the viral-rewrite skill inherits a proven reel structure. One input, two surfaces: the reel and its carousel twin.

## The flow (MEASURED from the demo)
1. **Input:** an idea, or a video that already did well for your profile. In the demo the input IS the reel's own script — the Claude chat shows the full spoken script pasted in as the prompt (f_012: "Building a carousel from this script, I just need two things first."). The video demonstrates itself: input = the script you are hearing.
2. **The skill asks 3 questions before building** (f_012 + f_015: "1 of 3"). Question 1, VERBATIM-FRAME: "Which brand colour should the carousel use? (Pick one or type your exact hex via Other.)" — multiple-choice cards with one-line descriptions + free-text fallback ("Something else") + Skip:

   - 2. Claude orange #D97757 — "Fits the 'Claude skill' topic"
   - 3. Neon green #22C55E — "High-contrast on dark"
   - 4. Purple #7C5CFF — "AI/creator vibe"
   (Questions 2–3 are NOT shown on screen — GAP, see below.)
3. **It writes the slides** — the script's beats become slides, one idea per slide.
4. **It shows three different designs; you pick one** (f_004: 6-slide dark carousel mockup grid, blue accents). The user chooses by looking, not by describing.
5. **It exports high-res images ready for Instagram.**
