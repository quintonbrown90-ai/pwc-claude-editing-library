Source: @kallawaymarketing reel DfPXiP0RhNl, 0–33.3s (MEASURED). "There
are over 100 different collections across formats, editing styles, visual
hooks, and signature series." (VERBATIM). "Inside of each collection, you
can click into any video, get the full transcript, as well as deep analysis
on the idea, topic, hook, and format." (VERBATIM). "This has been hand

## The rule
A reference library filed by four collection types — Formats / Editing
styles / Visual hooks / Signature series — where every filed video carries
its transcript + deep analysis (idea / topic / hook / format). The taxonomy
is the filing system; the click-in analysis is the contract (every reference
is analyzed, not just saved).

## Executable steps
1. The 4-way taxonomy (the filing system for Q's 333-video harvest):
   FORMATS (breakdowns — the format's anatomy) / EDITING STYLES
   (comparison / clone — the style, side by side) / VISUAL HOOKS (unusual
   image — the hook's visual) / SIGNATURE SERIES (case study — the series,
   end to end).
2. The click-in contract: every filed reference carries its DECODE.md
   (transcript + idea/topic/hook/format) — a reference without a decode is
   not filed, it is just saved. Q's harvest already does this; this part is
   the rule that enforces it.
3. "Hand curated": the quality claim is curation, not volume — 100+
   collections is his number; Q's library is curated by what Q actually
   uses (the harvest's Tier S / Tier A tags), not by count.
4. The library is the input to the Format Finder (the format-finder part)
   — the matrix is built from the filed references.

## Worked example (PWC)

collection. Keyword WAITLIST.

## Human-made check
The filing is done by a human (Muse) — the taxonomy is a judgment (which
collection does this belong in?), not an auto-tag.
