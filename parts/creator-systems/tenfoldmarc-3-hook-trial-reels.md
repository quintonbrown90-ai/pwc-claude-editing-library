# CREATOR SYSTEMS — 3-hook trial-reel method + variation taxonomy (@tenfoldmarc)

Source: @tenfoldmarc reel DfTT3nszegV (Nov 3, 2026; 34.6s; 57 likes / 145
comments; funnel REEL, free) + RABBIT-HOLE-MANIFEST.md. Verbatim Claude
prompt (PUBLISHED, on screen): "Make 3 trial reels. Use a different part of
the video as the hook for each." Also filed as PROMPTS.md §24.

## The rule
One recording → 3 trial reels. The hook is the variable, the video is the
constant. Each trial reel opens on a DIFFERENT part of the same video — the
test is which moment hooks, not which video wins.

## Executable steps
1. Record once (Q's talking-head take, through-edit standard, no pauses).
2. Prompt Claude verbatim: "Make 3 trial reels. Use a different part of the
   video as the hook for each."
3. The 3-hook script template: HOOKS ①②③ + BODY + CTA — the same body, three
   different openings, same CTA (Comment WAITLIST).
4. Post as trial reels (Q posts them himself from the Instagram app — trial
   reels are app-only for @yerrr__q; Muse supplies the daily three). The
   winner is the hook with the best 3-second hold, measured on real counts.
5. **Variation taxonomy** (from his Dep25/Dep585 thumbnails — the
   anti-duplicate rule for trial-reel variations): MIRRORED (same video,
   flipped) / NEW HOOK (same video, new opening) / NEW GRADE (same video,
   new color grade). Every variation is labeled with its type — a variation
   without a label is a duplicate, and duplicates burn the audience (his
   own 4th delivery of the same pitch collapsed to 16 likes / 17 comments —
   re-shooting the same pitch burns the audience; vary the VIDEO, not the
   pitch).

## Worked example (PWC)
One P-pack take → 3 trial reels: hook ① the claim ("BRANDS ARE PAYING
SMALL CREATORS LIKE YOU"), hook ② the proof tile first, hook ③ the question
re-cut as a claim. Same body, same WAITLIST CTA. Winner by 3-second hold
becomes the main post. Keyword WAITLIST.

## Human-made check
The three hooks are three different MOMENTS of the same video — not three
different scripts. The variation type is labeled on every file (MIRRORED /
NEW HOOK / NEW GRADE) so nothing ships twice by accident.

## PWC skin
Same body, same CTA, PWC palette. Trial-reel lane rules apply (Q posts
from the app; Muse supplies 3/day from the yapping pool).
