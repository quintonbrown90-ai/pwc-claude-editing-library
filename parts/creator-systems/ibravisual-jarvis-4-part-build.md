## The rule
"Build your own JARVIS." "ONE VOICE OVER YOUR WHOLE DAY." Four parts,
one voice: LISTENING over ENGINE / MEMORY / VOICE / FACE.

## Executable steps
1. **The loop (slide 02/08):** "You speak. It does the work." SPEAK
   (you say it) → ROUTE (Claude Code picks the skill) → EXECUTE (the
   skill does the work) → REMEMBER (saved to the vault). "NO TABS. NO
   TYPING. JUST TALK." "ONE LAYER OVER EVERYTHING YOU DO." Voice
   lines on the cover: "Jarvis, morning brief." / "Plan my day." /
   "Pull my numbers."
2. **Step 1 — wire the brain (03/08):** "Claude Code is the engine.
   Every job is one small skill file, loaded only when you ask for
   it." The skills/ folder: inbox/SKILL.md, plan/SKILL.md,
   metrics/SKILL.md, trends/SKILL.md, vault/SKILL.md. Terminal:
   "claude ~/jarvis / you: jarvis, morning brief / routing... / load
   inbox". "SMALL SKILLS BEAT ONE GIANT PROMPT." (Same doctrine as the
   library's own skill-doctrine part — one canonical doctrine, this is
   its JARVIS-shaped instance.)
3. **Step 2 — build the memory (04/08):** "One Obsidian vault.
   Everything lands as linked notes you can read." Three folders:
   raw/ ("everything captured"), vault/ ("what it learned"), outputs/
   ("what it shipped"). "NO DATABASE. JUST FILES." (Same .md-folder
   doctrine as the Operator OS vault part — one doctrine, two lenses.)
4. **Step 3 — add the voice (05/08):** "Hold space and talk. It hears
   you and answers out loud, all running locally." SPEECH → TEXT (YOU)
   / TEXT → SPEECH (JARVIS). "AUDIO NEVER LEAVES YOUR MACHINE."
   "PRIVATE BY DEFAULT." "YOUR MACHINE" — local-first is the point,
   not a detail.
5. **Step 4 — build the face (06/08):** "One prompt to Claude Code
   gets you the HUD. One screen for your whole day." The HUD:
   J.A.R.V.I.S. — TODAY, COMMAND DECK (brief / plan / metrics / close
   day). "ONE PROMPT. ONE EVENING."

## Worked example (PWC)
Q's morning brief, spoken: "Jarvis, morning brief." ROUTE loads
plan/ + metrics/ → EXECUTE reads the library (today's 3 posts, the
queue, the waitlist count) → REMEMBER writes the brief to the vault.
The HUD shows TODAY: the 3 posts + their keywords + the trial-reel
supply. Audio never leaves Q's machine; the HUD is PWC navy/teal/gold.
Keyword WAITLIST.

## Human-made check
"You speak. It does the work" only holds because the skills are small
and the vault is readable — a human can open any file and see what the
voice did. If a step can't be read back from a file, it isn't done.
