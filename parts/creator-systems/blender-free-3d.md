## The rule
Claude builds any OBJECT in Blender for free instead of burning
generation credits on every shot. Kappa's words: "With it, Claude can
build any object for free so you don't burn extra credits on every
single shot." Cost-saving rule for the 3D/object lane.

## Executable steps (rebuild)
1. Claude scripts the object in Blender's Python API (bpy) — primitive
   meshes + bevels + materials, no generation call.
2. Render transparent PNG/EXR (still prop) or a short turntable
   (object rotates 360°, 2–3s) for a moving prop.
3. Import into CapCut/HyperFrames as a prop layer; light it to match
   the scene (PWC: teal/gold materials on navy).
4. Verify the object reads at phone size before the real edit — a prop
   nobody can identify is a failed prop.

## Trigger rule
Use Blender when the video needs a THING (a numeral, a prop, a diagram
object, a product mockup) and no real photo of it exists. Never for
people, never for a face, never for proof — props only. Real-not-AI-flat
rule: a Blender prop is a built object, not a fake photo; it must never
stand in for a real screenshot, receipt, or person.
