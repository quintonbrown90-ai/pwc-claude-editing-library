## The rule
"My company's memory is a .md folder." "Obsidian is the viewer. The
files are the system." Agents read it before they act and write back
what they learn.

## Executable steps
1. **The vault:** transcripts, emails, decisions, and client state as
   markdown on disk. His count: 135 knowledge pages / 111 captures /
   25 live business state / 26 system files. Any Claude Code session
   on the machine can read and write it.
2. **Three layers, split by write permission:** immutable raw
   (transcripts, emails, articles — agents read, never edit);
   agent-owned synthesis (people, companies, concepts, decisions);
   mutable business state (clients, pipeline, projects — lifecycle
   and archive). "Sorted by who can write, not by topic. Topic lives
   in the links."
3. **One schema, the contract:** "Every page follows one schema."
   Frontmatter: type (person | company | concept | …), status
   (seeding | growing | evergreen), created, updated, tags, aliases.
   Ten page types, each with required fields. "Status is a trust
   level." "A write that fails it gets rejected." "The schema is the
   contract between the vault and the agents."
4. **Every session is an ingestion event:** "One standing rule in the
   global config: when real operational information surfaces in any
   project, write it to the vault. Without being asked. Quick captures
   land in the Inbox. Substantial items run the Ingest skill." The
   Ingest skill: save the source / update pages / cross-link / refresh
   the index. "Nine hook rules sit underneath and block or warn on
   commands, file writes, and deletions. Instructions decide what to
   capture. Hooks decide what can never happen."
5. **The dream agent (3am consolidation):** "Dream, as in memory
   consolidation during sleep. It pulls the day's signal, deletes
   duplicate things, merges the true things… then it rewrites the hot
   file, a 500-word summary of current state, and refreshes the
   index." Loop: 01 Orient / 02 Gather signal / 03 Consolidate /
   04 Prune and index. "My own chat turns outrank emails and existing
   pages. Every run logged with tokens and cost."
6. **The anti-invention test:** his benchmark shape, not his score —
   one agent, eight memory systems swapped underneath, 272 questions
   about what it had been told across 77 chats, plus 7 questions about
   facts that were NEVER stored, "to catch systems that invent
   memories." The trap questions are the steal: a memory system is
   tested on what it must refuse to invent.

## Worked example (PWC)
Q's vault is this library: every decode, every decision, every fix as
a file; MEMORY.md is the hot file; the weekly sweep is the dream
agent (orient → gather → consolidate → prune + index). A correction
("never use the denim photo again") lands once as a file and is read
before every thumbnail after. Status is a trust level: a part is
STAGED until QC passes, then IMPLEMENTED. Keyword WAITLIST.

## Human-made check
"My own chat turns outrank emails and existing pages" — Q's word
outranks the vault. The vault remembers; Q decides.

## PWC skin

same as this library. No new tool is installed; the vault design doc
