## The rule
The content system as a machine — reels go in, a style cycles, zero credits
used, renders come out. The machine is the metaphor; the doctrine is the
substance: hook + story-to-the-end beats fancy editing. The vending-machine
visual (a reel dispensed like a product) makes the system feel automatic.

## Executable steps
1. The doctrine as a gate: before any edit starts, the script must pass two
   checks — (a) the hook names the outcome in ≤2s, (b) the story has a
   payoff the viewer waits for (an open loop + a second before the
   midpoint). If either fails, the reel does not render — the machine
   rejects it. (Same deny-gate as jlee's frame-rate check: the render is
   blocked, not warned.)
2. The machine visual: a PWC vending-machine card — a reel drops in, the
   style cycles (teal/gold/navy), the render count ticks up. Used as the end
   card of system-explainer reels, not on Q's talking heads.
3. The "credits.used(0)" line: Q's system runs on his own Claude skills,
   not on per-render credits — the cost line is a proof point, not a
   feature.
