# CREATOR SYSTEMS — One Claude, a page per job, chained (Tier S, @jlee.mov)

Source: @jlee.mov reel Dd3zG1QT8sO, 0–80.4s (MEASURED). "One Claude, a page
per job, chained together." (VERBATIM). 12 agents, all the same Claude.
Anthropic "Building effective agents" (Sep 19, 2024) cited on screen. Chain:
competitor reels → uncovered topics (idea from a ~600K-view reel) → hooks
database ranked by views → script from checklist (voice rules first, what's
banned) → voice check + fresh reviewer → "I read it" → film → cut (best
take, pauses out) → captions/animations → cover options → file away, clear
footage. Doctrine (VERBATIM): "none of them are talking to each other so it
never confuses itself" / "I don't argue with it in the chat. I fix that
job's page."

## The rule
One Claude, one page per job, chained — each job is a separate page (a skill
file), each job does one thing, the output of one is the input of the next.
The jobs never talk to each other (no shared chat to confuse), and when
something is wrong you fix that job's page, not the chat. The "I read it"
beat is the handoff: the next job confirms it read the previous output
before it starts.

## Executable steps
1. The chain (Q's launch chain, 12 jobs — his 12, not jlee's): (1) harvest
   reference reels → (2) uncovered topics → (3) hooks database (ranked by
   views, from the hook miner) → (4) script from checklist (voice rules
   first, what's banned) → (5) voice check + fresh reviewer → (6) "I read
   it" → (7) film → (8) cut (best take, pauses out, through-edit standard)
   → (9) captions/animations (CapCut-native) → (10) cover options → (11)
   file away in the one-stack → (12) clear footage.
2. Each job is one skill file (one page). The job's page states: its input,
   its output, its rules, and what's banned. Nothing else.
3. The handoff: each job's first line is "I read it" — it quotes the
   previous job's output (one line) before it starts. If it cannot quote it,
   it stops and asks.
4. The fix rule: "I don't argue with it in the chat. I fix that job's
   page." — when a job misbehaves, the fix goes into that job's page (as a
   rule — see the correction→rule loop part), not into a chat argument.

## Worked example (PWC)
The script job's page: input = the hooks database (top 10 mined hooks) +
the voice rules; output = a script in Q's voice, second-person, with the
hook verbatim; banned = first-person proof claims, invented numbers, the
hidden app's name. When a script comes back with an invented number, the
fix goes on the script job's page ("numbers must trace to the proof
library"), not into a chat thread. Keyword WAITLIST.

## Human-made check
The chain is built by a human (Muse) — the jobs are Q's real workflow, not
a generic template; the "I read it" handoff is verified (the quote is real,
not faked).
