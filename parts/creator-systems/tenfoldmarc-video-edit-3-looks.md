## The rule
Three named, switchable looks + per-section look commands + best-take
rebuild. Bold / Cool girl / Cool dude as named looks; the look is a choice,
not a re-edit. Built on HyperFrames + faster-whisper; Google Fonts (SIL
OFL); Pixabay SFX.

## Executable steps
1. **Three looks (named, switchable):** Bold / Cool girl / Cool dude. The
   look sets the caption style, the color treatment, and the motion grammar
   in one choice. Q's version: the three looks are PWC-skinned variants
   (Bold = PWC teal/gold; the other two are Q-named looks in the same
   palette — never a look that breaks the brand law).
2. **Per-section look commands:** different sections of one video can run
   different looks (hook in Bold, proof in a cooler look) — the look changes
   on a section boundary, never mid-sentence.
3. **Best-take rebuild:** transcribe every take, keep the cleanest, zero
   dead air. The rebuild is take-level (best take wins), not word-level
   surgery.
4. **Words-behind-the-head cutout:** the title/hero words pass behind the
   speaker's head (matte-occluded) — depth, not a paste-on. Same device as
   the kienobifilms titles-behind-head part; this is the second independent
   sighting, which strengthens it.
5. Install line (verbatim, PUBLISHED): `Install this skill for me:
   https://github.com/tenfoldmarc/video-edit-skill` — then `/video-edit`.
   The install is NOT run here (license PARKED); the line is recorded so Q
   can install it himself if the license clears.
