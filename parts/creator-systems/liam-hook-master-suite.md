## The rule
A 9-skill hook suite that fixes the first 3 seconds. The router
(`hook-master`) runs eight smaller skills in order and hands back one card
you can film from (~400–550 words, no essay before it).

## The stages (8, in order)
1. **four-failures-check** — does the hook fail by delay, confusion,
   irrelevance, or disinterest? Points at the exact words or shot; says how
   many seconds pass before the topic is clear.
2. **viewer-panel** — six viewers watch the first 3 seconds: the
   doom-scroller, the sceptic, the beginner, the niche expert, the buyer, a
   rival creator; each says swipe or stay, and why.
3. **the-council** — the verdicts become the top 3 changes, ranked (buyer +
   beginner weighted most for a business; doom-scroller + niche expert for
   a creator).
4. **hook-formats** — rewrite the idea in six formats, each built on a real
   contrast: Fortune Teller, Experimenter, Teacher, Investigator,
   Contrarian, Magician (visual layer).
5. **niche-tuner** — swap generic words for the ones the audience uses, with
   proof they trust.
6. **visual-match** — first shot, on-screen text, and spoken words all say
   the same thing, using footage already shot.
7. **lock-in** — the next 1–3 sentences pay the hook off, and find the dead
   stretch that loses people.
8. **viral-scout** (any time) — patterns from real examples the user pastes;
   never invents what is "trending".

## Honesty rules (PUBLISHED, verbatim in the skill — adopt as-is)
Only the creator's facts at their true size (an average stays an average; a
count keeps its meaning; no invented times; only quote words the brief
contains); never promise views, reach, or virality; no trend claims without
data; decline misleading hooks in one sentence and give a true version that
does the same job; the footage must pay the hook off in the next few seconds
or it is clickbait; words, picture, and text agree. The card ends with
"Test it" (compare 3-second hold / average watch time against recent videos
— no predicted numbers) and "Check these" (max 3 facts to confirm before
posting). Blind-tested (their test, not verified by us) against dbs-hook
(27,292 installs) and ad-hook-analyzer (19,481 installs) with a separate
judge model; the README also lists its own slips ("60 loaves" count-meaning
slip, guessed timings) — the suite audits itself.

## Executable steps
1. Install (MIT): `git clone … && bash install.sh` (copies 9 skills into
   ~/.claude/skills, asks before replacing).
2. Run every Q hook through the full run before filming: four-failures check
   → viewer panel (Q's ideal avatar = the beginner/buyer; the sceptic = the
   "another guru?" viewer) → council → six formats → niche-tuner (Q's
   avatar's words, from his comments/DMs) → visual-match (first shot from
   Q's footage, usually the most surprising frame moved to second zero) →
   lock-in (next sentences pay the hook off; flag dead stretches).
3. Film the top pick, keep two backups.

## Worked example (PWC)
Hook "You posted 4 videos, then you quit" — four-failures: no delay (claim
at 0.8s), no confusion, relevant, not disinterested → PASS; viewer panel:
beginner stays ("that's me"), buyer stays ("the 5th video pays"), sceptic
stays ("prove it"); council top change: move the proof tile to 1.0s.
