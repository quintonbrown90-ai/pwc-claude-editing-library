# CREATOR-SYSTEMS — skill-pack anatomy: rulebook + lookbook + reference folder (PUBLISHED)

Source: Joseph Video Editing — youtube.com/watch?v=7g9Qm1e00zU
(PROMPT-PATTERNS.md §23; CLAUDE-CODE-WORKFLOWS.md §19/§21). Training prompt
verbatim from Joseph; five-key spec summarized.

## The rule
A trained Claude editing skill is THREE artifacts, built from 14 reference
videos + a 120+ image Figma breakdown board: (1) rulebook — font sizes,
spacing, layout, animation curves, movement speed; (2) lookbook — shapes,
colors, gradients, icon styles, assets; (3) reference folder — ~200
animations, each with a screenshot + keyframe sheet + breakdown of how it
works. A viral short-form style decomposes into exactly FIVE keys:
(1) captions — lower-third dark+blur box, 2 fonts (sans regular + script
highlight), script words first then sans around the gaps, pop-up blur
fade-in; (2) UI listicles — chapter markers (rhombus, slight gradient, thin
stroke, number center), shown early, reused with chapter name on every
mention; (3) UI pops + counters — before/after layout for comparisons,
notification pop-up (blurred bg + logo + text), circular timer, blurred-square
sequential lists; (4) hooks — 3-piece formula: speaker eyes aligned to upper
third + text emphasizing the one thing that makes the viewer watch + a
supporting visual; (5) full-screen animations — listicle timelines, single-
element scenes, high-contrast text scenes, out-of-screen zooms.
Two trainings before building: VISUAL (captions / animations / on-screen
animations) + SOUND (library + guide). Planning page: script left, empty
plan box right; for every line pick one of 4 scene types — captions /
captions+UI / half screen (animation top, speaker bottom) / full screen.
Human plans ~15 min; Claude follows the taste.

## Executable steps
1. Reference folder: download your 14 best edits in the style.
2. Figma board: split screen (Figma right, videos left), screenshot every
   good design scene until 120+ images; break down each of the 5 keys.
3. Training prompt (verbatim): "First you're going to break down the 14
   reference videos into a word-by-word transcript and a frame-by-frame
   breakdown. Then you're going to study three main things. The design
   principles of every scene, the colors, layout, effects and everything
   else, the animation logic, what does each element have as an animation,
   a pop-up fade-in, a [reveal] and so on, and the placement of the
   animations and timing relative to the script of the video. Then you're
   going to use the Figma breakdowns as a deep analysis of the design
   principles of this editing style. So study it and analyze how the styles
   [are] made. Learn everything there is to this editing style so that you
   can recreate it and turn it all into a skill."
4. Claude outputs rulebook + lookbook + reference folder.
5. Use: raw cut → planning doc (script lines + empty boxes; ask
   "recommend four potential designs for each scene") → human plans ~15 min
   → hand Claude the plan + skill → Remotion build ~40 min → review twice
   with a specific fix list → 10-min rebuild → Q-sheet sound pass.
