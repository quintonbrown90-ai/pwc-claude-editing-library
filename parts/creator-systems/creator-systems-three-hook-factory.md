# CREATOR-SYSTEMS — three-hook trial-reel factory + five-skill system (PUBLISHED)

Source: Emil Faschang — youtube.com/watch?v=1VqdsBPGmcE
(CLAUDE-CODE-WORKFLOWS.md §9–10). View/follower claims are his PUBLISHED
numbers, unverified. Model note (Nov 2026, re-check current): Opus 4.1,
"max effort not ultra — ultra overthinks, max is the sweet spot".

## The rule
Every raw recording becomes THREE trial reels, each with a different hook.
One recording batch (14 videos, ~25 min of recording) feeds the month's
trial-reel supply. The system splits into FIVE skills so each job has one
owner: competitor radar (topics + scripts from what worked for competitors),
research pipeline (ideas across platforms), scripted reels pipeline
(raw → ready-to-post), scheduling skill (Metricool), analytics + tracking
(Claude learns from posted videos to improve the next round).

## Executable steps
1. Record raw (mistakes, pauses, thinking aloud all left in).
2. Claude removes pauses/false starts/mistakes/coughs, adds captions +
   B-roll + music bed → output 3 variations with unique hooks.
3. Hook pattern, verbatim from Emil's example: (1) flat claim — "OpenAI just
   released a model that uses your computer like a person does." (2) question
   + claim — "Want AI to use your actual tools without building an
   integration for each one? OpenAI just released…" (3) provocation — "Did
   OpenAI just kill the virtual assistant industry…?"
4. Slash commands he uses: `/ideate` ("I want 20 reel ideas" — scrapes
   competitor, scripts them), `/scripted reels`, `/remotion reels` ("I just
   recorded XYZ video. Here's the video file. Please edit it for me"),
   `/schedule`.
5. Honest framing to copy: "30 minutes is our input once the system is
   built, but Claude Code will obviously be working for hours and hours" —
   report input time and machine time separately, never conflate them.
6. Skill files themselves were NOT downloaded (description link not chased);
   rebuild from the spoken spec only.

## Worked example (PWC)
One 25-min Q recording batch → 14 raw takes → 3 hooks each = 42 trial-reel
candidates; the trial pool (56 yapping items) is fed in hook-triples, and Q
posts trial reels himself from the app (trial reels are app-only for
@yerrr__q). Scheduling via Metricool in his setup; Q's lane uses the IG app
+ the standing queue.

## PWC skin
Hooks are Q's true claims; trial reels carry the keyword CTA; no hook is
posted without its ManyChat flow live (ENGINE Step-0 gate).
