# CREATOR SYSTEM — @kienobifilms: cut-list-first + storyboard gate (PUBLISHED)

Source: catalog `research/claude-editing-creators/kienobifilms/` +
decode DexbBiqBJRV. Tier S #1 in the IG sweep — closest to Q's lane.
Prompts VERBATIM. No DM gate ("no comment, no DM. Just save it").

## The rule
Claude never renders before the human approves the cut list and the
storyboard. The gates ARE the quality.

## The system (5 steps)
1. **5-step talking-head system** — the full pipeline, published.
2. **CLAUDE.md style memory** — the style lives in a file Claude reads
   before every edit (same pattern as Q's design system).
3. **Cut-list-first approval** — "Cut every silence, every retake, keep
   my last take — and show me the cut list first."
4. **Storyboard gate** — "Break this into frames and write me a style
   guide." Storyboard before render.
5. **Turn it into a skill** — "Turn this into a skill" closes the loop
   (the edit teaches the next edit).

## Executable steps
1. After the first cut, output the word-level cut list and STOP — no
   render until approved. (This is Q's pilot gate, automated.)
2. Storyboard the approved cut (frames + style guide) before rendering.
3. Save the finished edit as a skill file — the next video in the lane
   starts from it, not from zero.
4. Timeline export for Premiere/Resolve when the edit leaves Claude.
