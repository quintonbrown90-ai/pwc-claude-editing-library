## The rule
The hook doctor — every hook is diagnosed against the creator's own best vs
worst, frame by frame on the first 3 seconds, and must pass an 8-point
checklist before it is made. The diagnosis is comparative (best next to
flop), not absolute.

## Executable steps
1. Input: Q's hook (verbatim) + his 5 best hooks + his 5 worst hooks (from
   the harvest, with retention data where measured).
2. The doctor's pass: (a) lay the new hook next to the best and the worst
   — which does it resemble? (b) frame-by-frame the first 3 seconds: what
   is on screen at 0.0s / 1.0s / 2.0s / 3.0s? (c) run the 8-point
   checklist (the repo's checklist — port it verbatim from the MIT source,
   in PWC skin).
3. Output: PASS / FIX + the one line to change. A hook that fails does not
   get filmed.
4. The checklist lives as a skill file (MIT source, ported — license allows
   it; credit Ootto in the file header).

## Worked example (PWC)
Hook "You posted 4 videos, then you quit" — best-hook match: P1's "BRANDS
ARE PAYING SMALL CREATORS LIKE YOU" (claim in ≤2s, Q's face on screen);
first-3s frames: 0.0s Q's face + title drop, 1.0s claim, 2.0s proof tile;
checklist 8/8 → PASS. Keyword WAITLIST.

## Human-made check
The best/worst comparison uses Q's own reels, not Jayant's; the checklist
is a gate, not a score — a hook either passes or it is fixed.
