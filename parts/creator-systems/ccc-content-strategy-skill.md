## The rule
Interview → positioning → formats → scored ideas → first batch. The
deliverable is five videos to film, not a document to admire — it ends on
the next action.

## Executable steps
1. Weekly: Claude interviews Q (4 questions max — what happened this week?
   a client call, a number, a mistake — the /ig-plan inputs) → researches
   Q's niche (the outlier-multiple swipe) → writes the strategy doc.
2. Positioning one-liner (Q's: creators under 10K → deal-ready in 90 days)
   → 3 formats for the week → 15 ideas with MEASURED outlier multiples
   (views ÷ Q's median — never estimated; see the variant note below) →
   first batch of 5 to film.
3. Q approves the doc (pilot-gate) → first batch of 5 filmed. The doc lives
   in the one-stack with the week's videos.
4. Skeptic Q&A dialogue: Q + Kiya, or Q + avatar, doing the
   objection-handling beat.

"700M+ client views" are the creators' claims, UNVERIFIED — never repeated
as Q's numbers. Q's doc uses Q's real numbers only.
