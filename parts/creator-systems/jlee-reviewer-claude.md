# CREATOR SYSTEMS — Reviewer Claude critic pass (Tier S, @jlee.mov)

Source: @jlee.mov reel DemOzcbiJOm, 38.2–52.0s (MEASURED). "Then those
scripts go to a separate Reviewer Claude whose only job is to find what's
wrong." (VERBATIM). The three things it catches: a wrong-cause stat, an
untraceable quote, a stale-by-posting-day claim. Gist code is license-unclear
(no LICENSE statement) — reconstruction/draft only, never verbatim code.

## The rule
A separate Claude whose ONLY job is to find what's wrong — not to fix, not
to praise, just to find. The reviewer is separate (a fresh Claude, not the
writer) so it has no stake in the draft. The three catch-categories are the
reviewer's checklist.

## Executable steps
1. The reviewer runs AFTER the script is written and BEFORE filming. Input:
   the script + the proof library (the sources for every claim in it).
2. The reviewer's checklist (his three, ported): (a) WRONG-CAUSE STAT — does
   the script claim X caused Y when the proof only shows X happened near Y?
   (b) UNTRACEABLE QUOTE — is every quoted line traceable to a source (a
   file, a frame, a link)? (c) STALE-BY-POSTING-DAY — will any claim be out
   of date on the day it posts (a date, a price, a count that moves)?
3. Output: a list of findings, each with the line number + the fix (a
   correction, not a rewrite). The writer fixes; the reviewer does not
   rewrite.
4. The reviewer is a FRESH Claude (no memory of the draft) — the separation
   is the point. In Q's operation: the reviewer's pass is a separate skill
   invocation with only the script + proof library as context.

## Worked example (PWC)
Script claims "2.9 million views" for the wall tile — reviewer flags it:
the wall shows 2.8M (Tile 11 is Adley's 2.8M Nashville video), the spoken
line is wrong (Q's own Nov 8 ruling: leave it at 2.8). Fix: correct the
audio to 2.8. Keyword WAITLIST.

## Human-made check
The reviewer finds; a human (Muse) judges whether the finding is real
before the fix is applied — the reviewer is a critic, not an editor.

## PWC skin
The proof library is Q's harvest + Skool positioning + verified numbers.
Nothing the reviewer flags becomes a fix until Muse verifies it.
