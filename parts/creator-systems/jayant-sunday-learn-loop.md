# CREATOR SYSTEMS — Sunday LEARN loop (Tier S, @jayantcreates.ai)

Source: @jayantcreates.ai reel De4O-CaD6lD, 24.1–33.8s (MEASURED). "LEARN
— the smart one. Every Sunday, it studies how each reel did and rewrites
the next one." (VERBATIM). The 5 jobs: STUDY / WRITE / BUILD / REPLY /
LEARN. The Ootto repo is MIT (usable); the DM-gated skill files are his
commercial product — NOT adopted, not downloaded. Do NOT chase any DM.

## The rule
A weekly review job reads last week's results and rewrites next week's plan
— the system improves itself on a fixed day, not when someone remembers to.
The Sunday is the discipline: same day, every week, no exceptions.

## Executable steps
1. The LEARN job (a Claude skill, not a person): every Sunday, read the
   week's posted reels + their retention/engagement (from the harvest + IG
   insights), and write a one-page "what worked / what didn't / what
   changes" note.
2. The note has three sections: (a) the best hook of the week (verbatim +
   why it worked), (b) the worst drop-off point (timestamp + what was on
   screen), (c) the one change for next week (a single rule, written as a
   correction→rule card — see `parts/creator-systems/jlee-correction-rule-loop.md`).
3. The next week's scripts are written against the note — the first line of
   every script brief is the previous week's one change.
4. The loop is visible: the Sunday note is filed in the stack (one file per
   week, dated), so the improvement is traceable — week 3's rule cites week
   2's failure.

## Worked example (PWC)
Sunday Nov 15 note: best hook "You posted 4 videos, then you quit" (held
82% to 3s); worst drop-off 0:41 (the board cross-faded over Q's face — the
freeze/transition gate violation); one change: "boards cut in hard, never
cross-fade". Week Nov 16 scripts open with that rule. Keyword WAITLIST.

## Human-made check
The note is written from Q's actual numbers, not generic advice; the one
change is one thing, not five.

## PWC skin
Filed in the one-stack with the week's videos; teal/gold on navy. The loop
feeds the correction→rule file, never a chat thread.
