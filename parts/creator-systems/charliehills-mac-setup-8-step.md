# CREATOR SYSTEMS — the 8-step one-folder edit system (@charliehills)

Source: @charliehills Mac-setup carousel, complete in the harvest (cover
De_3uzBCHe2 + steps 1–8 + CTA De_3ux6CD0g), silent slides, on-screen text
only (PUBLISHED). The CTA deliverables (full prompt + 7 installs + break
fixes) are GATED behind comment EDIT — never chased. Rebuild from the
visible slide specs only, labeled INFERRED where the slide shows the
shape but not the file.

## The rule
7 installs · 1 folder · no editing app. The whole edit lives in one
folder; the prompt is saved once as a skill; the storyboard is the gate
before any render; every note becomes a rule for next time.

## Executable steps
1. **Install once:** Claude Code, Homebrew, ffmpeg, Node.js, Whisper,
   Puppeteer, a skill file. "Install them once. All free, bar a paid
   Claude plan." (ffmpeg, Node.js, Whisper already in Q's operation —
   the list confirms the stack, it does not add to it.)
2. **Make one folder:** you put in 4 things — raw-take.mov (one take,
   mistakes fine), references/ (5 outlier videos), brand.md (colours,
   font, captions), best.mp4 (the edit to beat). Claude adds 2 more as
   it works — reference.md, moves.md.
3. **Save the prompt as a skill:** "Paste my full prompt once and tell
   Claude to save it. Every edit starts from the same rules." Folder
   spec on screen: my-video/ raw-take.mov, references/ (5 outlier
   videos), moves.md (built on the first run), brand.md, notes.md
   (every note, as a rule), best.mp4. Read order: brand.md, moves.md,
   notes.md before any work.
4. **Add 5 outlier videos:** "Videos with 5x the creator's usual views.
   Claude learns the hook, the pace and the layouts." moves.md keep
   rule: kept when 2+ outliers do it. His three moves: HOOK — name the
   feature as a typed action inside 4 seconds; PACE — a new shot every
   1.3 to 2 seconds; LAYOUT — the real app on top, your face in a
   rounded box below.
5. **Type "edit this video":** the trigger is one line; the saved skill
   supplies the rules. Claude cuts the pauses and the retakes, then
   shows the cut list: "Here is the cut list. Good to go?"
6. **Say yes to the storyboard:** "One still per beat. Nothing renders
   until you say yes." The yes is the gate — this is Q's pilot gate in
   his shape (judge the pilot before the batch is built).
7. **Claude checks its own work:** "Before you ever see the render."
   Four checks: screenshot every 0.25s (212 of 212 frames); flag
   overlaps and crops, fix, check again; clear of Instagram's buttons;
   as many graphic changes as best.mp4. Loop: flag → fix → check again.
8. **Give notes, get final.mp4:** "One note at a time. Each one becomes
   a rule for next time." "All 4 checks pass. Here's your render."
   Notes land in notes.md; the next edit needs fewer notes.

## Human-made check
The storyboard yes-gate and the notes-become-rules loop are the human
in the loop — nothing renders unjudged, and every correction compounds
into the next edit instead of being re-typed.

## PWC skin
PWC brand.md replaces his colours; his caption note ("Captions always
in the middle, ideally never on my chin") converges with Q's rule —
captions center-lower, never over the face; Q's rule governs. No red
anywhere; the 0.25s screenshot check runs against Q's safe zones
(x 70–930, y 280–1480).
