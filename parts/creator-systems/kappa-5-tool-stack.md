## The rule
One file, drop into Claude Code, self-installs (Mac + Windows, local, no API
keys/subscriptions — their claim). The stack gives Claude one missing sense
per tool:
1. HyperFrames (video engine, Apache-2.0) — where the project lives; the edit
   is HTML + GSAP timeline rendered to MP4. Remotion is the named alternative.
2. Whisper (speech->text, MIT) — Claude hears every word; word-timed subtitles.
3. CLAP (audio understanding, MIT/CC0) — Claude knows what each sound is;
   similarity scores label sounds (downward sweep 0.66, bubble_pop 0.51, key
   press 0.87) and find similar sounds in a library.
4. Demucs (stem split, code MIT / weights FLAG — research use only) — splits a
   track into voice/drums/bass/other so music and effects separate. See
   parts/audio-sound/audio-demucs-stems.md for the flag.
5. Blender (free 3D, GPL) — Claude builds any object for free instead of
   burning generation credits (their credits chart: Higgsfield 1,240 /
   Midjourney 960 / Kling 1,080 / Blender 0).
Optional paid add-on: Higgsfield via MCP for harder shots — note only, never
required.

## Executable steps
1. Install order: HyperFrames -> Whisper -> CLAP -> Demucs -> Blender.
2. Verify each with one test render before the real edit.
3. Blender only for props/diagrams, never fake people (real-not-AI-flat rule).
4. Slot the stack under the router as the "toolchain" row: which engine +
   which ears + which sound tools for this video.
