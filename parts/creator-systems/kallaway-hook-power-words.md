# CREATOR SYSTEMS — 6 hook power words (Tier S, @kallawaymarketing)

Source: @kallawaymarketing reel DfFWzxGxWWH, 0–101.8s (MEASURED). "Every
winning hook should have the subject clarity word, the action word, the
objective word and the contrast word. Now the last two hook power words are

## The rule
A 4-word checklist for any hook — subject clarity + action + objective /
state-change + contrast. The contrast word (base state vs end state) is
ranked first in importance: the transformation (0 → 100K) is what ratchets
up curiosity. Words 5–6 are optional multipliers (gated — not in this part).

## Executable steps
1. The checklist (4 lines, one per word): (a) SUBJECT — does the hook name
   the subject (I / you / we)? (b) ACTION — does it name the action the
   subject takes? (c) OBJECTIVE — does it name the end state (the result)?
   (d) CONTRAST — does it name the base state, so the transformation is
   visible (0 → 100K)?
2. The contrast curve: draw the base state → end state as a rising curve
   (teal line, gold endpoint) — the transformation made visible as a slope.
   The curve lands on the contrast word.
3. The parse: teach by annotating ONE hook four times (his worked example:
   "If I had to grow from 0 to 100K subs on YouTube, here's how I'd do it"
   — I / had to grow / 0 to 100K subs / 0 vs 100K). Q's hook teaching uses
   the same parse on his own hooks.
4. The gate: a hook missing any of the four does not get filmed — it goes
   back for a rewrite. The hook doctor (the Ootto virality part) runs the
   same checklist as one of its 8 points.

## Worked example (PWC)
Hook "You posted 4 videos, then you quit" — subject: you / action: posted
(then quit) / objective: the 5th video that pays / contrast: 4 videos
(quit) vs the 5th (pays). 4/4 → PASS. The contrast curve: 0 → first brand
deal, drawn as a rising line. Keyword WAITLIST.

## Human-made check
The four words must all be Q's words (his script), not added by the checker
— the checklist finds what's missing, it does not write the hook.
