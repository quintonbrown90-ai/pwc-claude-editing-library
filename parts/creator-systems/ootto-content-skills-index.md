## The rule
One repo, one team: every skill does ONE job in the pipeline. Memory →
study → create → distribute → lead-gen. Reach for the skill by the JOB, not
by the name.

## Executable steps
1. Name the job (study / create / plan / distribute / lead-gen / measure).
2. Pick the skill from the map above; if it is one of the five with its own
   part, read that part — it carries the PWC re-skin.
3. Run the skill, then run the humanizer on its output before anything is
   filmed or posted (Q's HUMAN-MADE CHECK).
