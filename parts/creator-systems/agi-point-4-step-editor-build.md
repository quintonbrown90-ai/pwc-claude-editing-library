# CREATOR SYSTEMS — build your own AI video editor in 4 steps (@agi_point)

Source: @agi_point reels De7I8o0iBHe (4-step build, PUBLISHED — spoken
verbatim) + De5VcwvFTMK (narrated live-build, same system, prompts
named per step). The free guide (every prompt from the video) is GATED
behind comment EDIT — never chased. The exact install/style/edit prompt
TEXT is shown on screen but was not captured verbatim in the decodes —

## The rule
"Everyone is editing their reels with Claude Code now, but nobody
shows you how. So here's every step, every prompt, and every tool to
build your own AI video editor. For free." The style sheet is approved
BEFORE the edit, not discovered after — and the storyboard is shown
before the render.

## Executable steps
1. **Step 1 — set it up:** "Get Claude Code, the desktop app, not the
   browser. Make a folder called AI video editor with three folders
   inside. Raw footage, references, and exports. Open a new Claude
   Code chat, choose local, and pick that folder." (Same 3-subfolder
   shape as the aiwithrone / andreakyton setups — one canonical shape,
   this is its 4-step instance.)
2. **Step 2 — install the tools:** the install prompt names the stack —
   HyperFrames (motion graphics), FFmpeg (cuts), Whisper (transcripts),
   yt-dlp (downloads). Each tool is named only here; HyperFrames is
   already Q's skill, ffmpeg/Whisper/yt-dlp are already in Q's
   operation. No new tool is installed by this part.
3. **Step 3 — lock the style sheet:** "3–5 reels → style sheet for
   approval." Claude writes the style sheet (fonts, cuts, captions,
   music) from the reference reels, and the human approves it BEFORE
   any edit runs. The style sheet is the lock: every edit after it
   follows the same sheet. (Same shape as the graphic-designer
   REFERENCE.md — one lock doctrine, this is its video instance.)
4. **Step 4 — edit, storyboard-first:** "Drop raw → cuts + captions +
   music + motion + storyboard first." The edit prompt drops the raw
   footage in and Claude shows the storyboard FIRST — the storyboard
   is the pilot (judge the plan before the render — Q's pilot gate,
   his shape). Then revise like a human editor: tell it what to change,
   it rebuilds — no timeline, no software.

## Worked example (PWC)
Q's folder: AI video editor/ raw/ (his talking head, one take,
mistakes fine) / references/ (5 outlier reels) / exports/ (finished
reels). Style sheet: PWC palette, Anton headline, captions
center-lower never over the face, SFX on every entrance, Water Line
under the thesis block — approved by Q once, then every edit follows
it. Storyboard first, Q says yes, then the render. Keyword WAITLIST.

## Human-made check
Two approvals, not one: the style sheet is approved before the first
edit, and the storyboard is approved before each render. An edit that
skips either approval is an edit that invents its own style.
