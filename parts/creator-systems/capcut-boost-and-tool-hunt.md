## THE VERDICT THAT GOVERNS EVERYTHING
No challenger honestly beats CapCut end-to-end for Q's work — his Sky grammar IS
CapCut-native caption animations, template IDs and effect motion; no other editor
renders those. So the strategy is LAYERS around CapCut, not replacement:
generation → rough cut → caption timing → CapCut draft assembly → CapCut finish →
quality layer when source is weak. Closest challenger if he ever outgrows CapCut:
DaVinci Resolve Studio ($295 one-time; free tier complete; Neural Engine AI captions
+ Super Scale upscale; Python/Lua scripting) — a finishing/color complement today.

## TOP 5 (ranked, all ADOPT-CANDIDATES)
1. **VectCutAPI** (github.com/sun-guannan/VectCutAPI — Apache-2.0, 2,371★, active) —
   BEST BOOSTER. Local HTTP server + MCP server that builds REAL CapCut draft
   folders from code: Claude assembles cuts, caption text and pop-up placement as a
   native draft; the finish still happens in CapCut, so Sky grammar is preserved.
   HONEST FLAGS: unofficial / reverse-engineered; CapCut ToS §6 bans scripted access
   (per wireflow.ai's reading); drafts must be version-matched (JianYing 6+ encrypts
   draft_content.json; CapCut 8.4/8.7/9.3 have rejected old-format drafts) and
   human-opened. Runner-up booster: capcut-cli (MIT, 1,157★, zero-dep Node CLI,
   edits existing drafts in place). Also: capcut-mate (Apache-2.0, 2,132★,
   JianYing-first — weaker fit for US CapCut).
2. **fal.ai** — official MCP server + one API key for 100+ generation models
   (Seedance / Kling / Veo / Wan / FLUX…), pay-per-use, no subscription. The breadth
   layer BESIDE Higgsfield (Higgsfield stays a first-class asset/motion factory —
   Q's standing order). Draft at 480p first to keep costs sane. Sign-up + credit
   purchase is a human step.
3. **ElevenLabs Sound Effects API** — text-to-SFX at $0.12/min via API; generates
   the exact missing whoosh/riser/stinger from a text brief inside the pipeline.
   Q's existing $6 Starter already unlocks commercial use — effectively pre-paid.
   Same account: Audio Isolation API (voice cleanup).
4. **video-use** (browser-use org — MIT, 30,909★) — agent editing over a packed
   Markdown transcript; EDL cuts snap to word boundaries, never inside a syllable.
   The rough-cut discipline layer before CapCut (uses ElevenLabs STT on his account).
5. **WhisperX** (BSD-2, 25,215★) — forced-alignment word timing, materially more
   accurate than Whisper's native timing; feeds his owned designed-caption systems.
   The cheapest quality upgrade in the caption lane.
