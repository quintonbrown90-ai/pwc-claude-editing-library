# CREATOR SYSTEMS — skill templates: frame.md + design.md (@thecuttingedge.school)

Source: @thecuttingedge.school reel De_XFh_O8-4 (HyperFrames skills, Nov
2026) — INFERRED reconstruction. The closest published description of how
HyperFrames skills templatize a look — directly relevant to Q's Sky-style
system (a fixed template + replication).

## The rule
Skills = reusable style. Fix the template once, replicate every video in that
style. frame.md = the frame (composition, safe zones, where the head sits,
where text sits). design.md = the design (palette, fonts, caption grammar,
motion grammar). One template, every video.

## Executable steps
1. **frame.md:** the composition contract — canvas 1080x1920, safe zones
   (x 70–930, y 280–1480), head position, text bands (top band for thesis,
   lower-third for captions), PiP corner for the face during screen demos.
   (NOTE: the source video is landscape-in-vertical with black bars — wasted
   canvas; Q's versions are vertical-native.)
2. **design.md:** the design contract — PWC palette (teal #14A886 + gold
   #FEE238 on navy #00214E, NO RED), fonts (Anton headline, caption style),
   caption grammar (Sky exact: one word at a time, keyword in accent color),
   motion grammar (hard cuts, punch-in zooms, tick on every caption word).
3. **Replicate:** every new video starts from frame.md + design.md — no blank
   page, no re-deciding. The template IS the style; the content changes.
4. **First-draft framing:** HyperFrames output is a FIRST DRAFT a human
   editor finishes — the honest framing Q needs (Claude drafts, human
   polishes), vs the "fully automated" claims elsewhere.
5. **Timestamp-level revision:** ask Claude to make changes at a particular
   timestamp — revision-by-timestamp, not re-render-everything. Same as Q's
   one-message feedback with timestamps.
6. **Four-use-case demo structure:** promo-from-website → new-product launch
   → edit-raw-footage → origin story. For Q: promo from waitlist page →
   new-cohort launch → edit a talking-head take → Q's origin story. A
   ready-made demo script structure.
7. **Cost framing:** "no credits apart from Claude" — open-source agent, no
   per-video credits. Same point as kappa's credits chart, in one sentence.

## Worked example (PWC)
Sky protocol as frame.md + design.md: the Sky form (frame) + PWC palette and
caption grammar (design). Every Claude edit starts from the pair; Q's face
stays in the corner PiP during screen demos, never covered.

## Human-made check
A video built from the template still gets the full watch-through — the
template is the start, not the QC.

## PWC skin
Teal/gold on navy, NO RED. Vertical-native 1080x1920. Nothing over the face.
